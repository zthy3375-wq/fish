# 邯院通 iPhone 原生开发版

基于正式 Android 1.2.1 对应 main `780bbc8`，独立 Swift + SwiftUI 工程，最低 iOS 16，仅 iPhone。没有 Flutter、Capacitor、Vue 运行时依赖。复用现有应用图标、校园头图、平面图以及已核验的学校协议读取脚本；iOS 在固定结果出口仅补充 resolvedTerm 元数据，避免课表失败时将其他学期的考试误并入缓存，不改变请求端点或参数。WebKit 只用于官方学校认证与页面查询，产品页面为原生 SwiftUI。

## 构建

在装有 Xcode 的 Mac 打开 `Hanyuantong.xcodeproj`，选 Hanyuantong scheme 和 iPhone 模拟器。

```sh
python3 Scripts/generate_project.py
xcodebuild -project Hanyuantong.xcodeproj -scheme Hanyuantong -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- test
```

新增 Swift 文件后重新生成工程。工程生成器只使用 Python 标准库，不需要 CocoaPods、Flutter、XcodeGen 或第三方 Swift 包。真机需要在 Xcode 选择自己的签名团队、可用 Bundle ID 与已信任设备；没有替用户配置签名、发布 IPA 或商店提交。CI 模拟器使用 Xcode 本机 ad-hoc 签名以保留 Keychain 运行时权限，不使用开发者证书，也不是设备分发签名。Simulator app 不能安装到真实 iPhone。

## 当前实现与边界

- 首页、课表、待办、我的四导航，原配色与现有图像资源；日/周课表、课程详情、个人课程创建/编辑/删除、丰富待办管理；首页下一节课、今日待办和近期考试。
- 学校官方 WKWebView 登录，现有 `syncAll` 查询和渲染页课表回退，成绩、考试、实践课、学期选择。密码只在学校官方页面输入。账号、查询、取消、超时与退出流程原生管理。
- 登录 Cookie 保存在设备专属 Keychain，WebKit 使用非持久化数据仓库；仅允许学校 HTTPS 主机及 443 端口，不忽略 TLS 错误，不向产品 UI 提供 Cookie。
- 学校记录与个人记录分开，以 CryptoKit AES-GCM 和设备专属 Keychain 密钥加密，排除系统备份。查询失败保留同账号同学期旧数据；账号替换、过期、退出移除学校缓存，保留个人安排。
- 个人数据支持 iPhone v1/v2 完整备份，以及 Android v1/v2 课表和待办 JSON 导入/导出。所有学期、作息和丰富待办字段保留，先预览、再确认替换或按编号合并；不兼容字段明确拒绝，不静默裁剪。上限5MB，个人当前学期2000条安排、原生5000条待办（Android导出500条）。写入加密临时文件及保护元数据后原子替换，提交成功才更新页面。备份不包含学校账号/记录；导出文件为明文，由用户选择保存位置。
- 东西校区平面图、缩放和全图复位。教学周按北京时间计算，起点沿用 2026-09-14 并允许手动校准；默认13节作息沿用用户提供表，不声称学校实时校历。
- 第二阶段已加入学习通官方登录、课程关注、作业/考试/通知查询、暂停续查、官方页面查看和本机计划；不自动提交作业或把本机计划当作官方完成状态。
- 趣智原生登录、余额、按月消费记录和8位使用码；胖乖原生短信登录、余额/券/记录、设备扫码、洗衣/饮水报价及显式确认。支付宝充值、SDK付款、签约与蓝牙设备通过固定官方入口完成；返回不等于支付成功。协议沿用已核验 Android 端，尚需真实 iOS 服务端兼容验收。
- CSV/XLSX/ICS 课程文件本机解析、字段映射、预览、重复/冲突提示和确认合并/替换；不执行公式、宏或外部资源，超限或不支持的日历规则明确拒绝。个人记录写入成功后才更新页面。
- 个人课程/待办系统提醒默认关闭，用户开启后请求通知权限，最多近期60条并在打开 App 时续排。WidgetKit 扩展提供今日课程，默认关闭，使用 App Group 加密副本与共享设备专属 Keychain；须用自己的开发团队正确配置 App Group/Keychain Group 才能真机工作。未注册这些能力时明确报错，不回退到明文。
- 快递官方入口与应用内页面见下述取件边界。不会冒用 Android 的拼多多 scheme。帮助页提供现有 QQ 群号和系统分享面板的脱敏状态反馈。
- 个人多学期与1–24节作息管理、课程多安排、单双/指定周、作息切换预览和删除确认。学校校历与个人学期独立，切换个人学期不会改算学校课程周次。
- 待办支持日期/时间/截止、关联课程、优先级、置顶、子任务、准备状态、重复、稍后提醒和筛选。新待办默认未安排，不隐式增加提醒；重复完成/撤销与导入关系有身份校验，不删除已经修改的下一次任务。
- 成绩保留学校绩点与课程/考试标识，支持分学期和类型筛选、数值加权、学校绩点加权、学分汇总；重修多次与身份不明记录不擅自选最高分。学校资料只读、账号隔离，不进入个人备份、小组件或统计。
- 昵称/专业、浅色/深色/跟随系统与紧凑布局在本机加密保存，恢复默认需确认。默认浅色保持原外观。
- 取快递包含隔离的应用内官方页面。动态出库“身份码”只在官方页显示；用户主动读取已核验待取页时，才将可识别的包裹“取件码”展示为原生卡片，可放大、复制和标记本机已取。仅当前页，不声称全量同步；账号/字段无法核验时保留官方页与固定系统入口。未迁移实验分支的内部签名补查或请求改写，没有真实非空取件码/iPhone验收。
- 匿名统计的选择、关闭、删除重试状态机已实现，但当前 iPhone build1 不满足现有服务端版本门槛，生产 gate 明确关闭，既不采集也不上报。后续开放需要独立的接口、删除保障和隐私披露核验，不能冒报 Android 版本；本次没有修改线上统计服务。
- 支付 SDK、蓝牙及第三方平台特有能力仍使用明确标注的官方入口，不声称原生设备操作全覆盖。真机签名、通知/小组件、官方登录/验证码、支付到账、设备启动与非空取件码均需真实环境验收。完整新代码必须通过新 CI；此前核心成功记录不覆盖后续新增代码。不会接入 Android 在线更新配置。

## 验证原则

单元测试覆盖来源限制、学期校验、账号隔离、失败缓存保护、周次解析、备份校验与加密存储读写；UI 测试覆盖四导航、重复打开/取消编辑器、待办保存后退出重开、完成筛选并保留截图。它们均使用合成输入和空账号，不等于真实学校登录验收。需在真实 iPhone 手工核对学校登录、验证码、学期切换、课表完整性、成绩、考试、离线重开与退出再登录。

所有工作留在独立功能分支，不更改现有 Android、线上服务或发布元数据。阶段验证记录见 `VALIDATION.md`。

## Xcode 16.4 模拟器兼容

Apple 已确认 iOS18.4/18.5 模拟器调用部分 WebKit Swift API 时，较低部署目标可能找不到 libswiftWebKit.dylib（[WebKit 293831](https://bugs.webkit.org/show_bug.cgi?id=293831)）。CI 优先选择最新可用运行时；若落在这两个版本，仅该模拟测试构建按官方方案覆盖部署目标为18.4。工程及独立 unsigned iPhone Release 构建仍为 iOS16。此处理不等于验证真实 iOS16设备；本地同版本模拟器可使用该测试覆盖或 Apple 文档中的运行时库路径方案。
