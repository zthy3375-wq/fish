# iOS 取件中心实现与验证边界

原生入口 `ParcelCenterView()`。本目录由当前 iOS 授权新增，不合并或修改 Android 分支，不变更线上配置。

## 来源

- 正式 Android 1.2.1 /145：main `780bbc85c0b70e8d9273129eca666d7141e21e42`；[PR #57](https://github.com/zthy3375-wq/fish/pull/57)。生产版使用固定官方外部入口，并不抓取账号或取件码。
- 已合并的[入口修复 PR #50](https://github.com/zthy3375-wq/fish/pull/50)：淘宝官方 HTTPS 身份码页；拼多多 Android 专用 scheme；App 首页和系统入口回退。Android scheme 不作为 iPhone 支持承诺。
- 未发布、未合并的[快递试验 PR #48](https://github.com/zthy3375-wq/fish/pull/48)，分支 `feature/parcel-native`，固定提交 `dd3ba77943091c5e05099d6b83745bff9654b644`。已读取该提交的 ParcelWebPolicy、ParcelPageWorker、ParcelStore、ParcelTaobaoQuery、collector.js、read-pending.js 及设计记录。PR 只记录用户确认两平台身份码可获取，未完成真实非空取件码验收。

iOS 依据该仓库的固定官方路径和明确 DOM 字段重写只读适配器。没有引入 HandyCode 代码或其页面重排资源，没有移植内部 MTOP 签名查询、响应拦截、PDD 同源代理、购物订单抓取或反爬参数生成。不能把 Android 试验的测试记录算成 iPhone 验收。

## 当前行为

1. 用户打开平台的官方待取页或身份码页，在平台官方网页输入密码/验证码。所有页面使用每个平台独立的非持久化 WKWebView，禁止任意 scheme、非白名单导航、HTTP、本地资源、下载和媒体权限；没有原生 JS 消息桥，不修改官方用户代理或 TLS 校验。
2. 用户点击“读取当前页取件码”才在隔离的 client world 执行一次只读 DOM 脚本。不读表单值或 JS 账号，不发额外请求，不轮询，不把跳转/打开/空 DOM 标成读取成功。
3. 只接受固定待取页面中显式取件字段，保留前导零；拒绝手机号式长数字、未知形状、隐藏节点、可见登录和验证画面。部分页始终标为部分，不保证完整分页或订单覆盖。
4. Native 层在观察前后核对稳定数字账号 cookie（淘宝 `unb`、拼多多 `pdd_user_id`）。缺失、冲突、变化、登录过期时不合并旧账号数据，提供官方页回退。不会用昵称、手机或轮换 token 猜测账号身份。
5. 读取确认后，Cookie 和本机取件码在同一加密信封中原子保存，按平台隔离，账号哈希复核。使用 ProtectedStorage 的 AES-GCM、设备专属 Keychain 密钥及备份排除；不会存入个人 JSON 导出/Widget/统计。原生卡片支持放大、复制、仅本机已取及撤销。
6. 已成功读取的历史码带时间。失败/部分/当前页明确空状态均不删除既有成功记录，不把本机标记或缺项当平台已取。只有明确账号切换、失效或用户清除才移除对应平台记录。不能区分同平台、同站点、相同货架码下的多个包裹，所以这里按码而非包裹/订单计数。
7. 缓存信封最多保留7天，稳定账号或Cookie失效时不恢复。退出清除本机该平台信封和临时WebView；不注销官方App。清除失败会隐藏记录并阻止写入，提示重试，不宣称清除成功。
8. 动态身份码不采集、不截取、不生成、不离线保存，只在官方页面显示。切到后台关闭浏览器与放大页，隐藏原生码；复制采用本机剪贴板且60秒过期。

## 明确限制

- 当前是“原生已读码卡片 + 应用内官方页面”方案，不是已验证的全量原生同步。官方页面的 DOM、iOS WebKit、登录/验证码/弹窗和现场扫码均未经真实账号验证。
- 登录仅在一次成功读取且稳定账号可核验时随缓存保存。仅查看身份码、缺少稳定账号字段或官方页无法识别时，关闭后可能需要重新登录；不通过降低账号隔离来隐藏此限制。
- 拼多多可能依赖未移植的同源兼容逻辑，或不提供稳定账号 cookie；此时不能承诺应用内提取。可保留官方页查看，或点固定官网系统入口。没有声称 iPhone scheme 直达可用。
- 白名单宁可拒绝未知官方跳转，也不自动放宽。增加来源必须先核实具体官方路径和用途。网页支付、确认收货、账号更改等用户在官方页自行操作，不由该读取器自动执行。
- 只使用合成代码/账号字符串作测试，未登录任何真实账号，未请求短信，未处理验证码，未完成实际取件。
