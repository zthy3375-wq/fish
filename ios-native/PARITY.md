# 邯院通 Android / iPhone 对照

Android 基线为 test.30（56b2da3），另按 test.31（49dd6a6）更新「我的社区」。五个一级入口依次为首页、课表、社区、待办、我的。iPhone 使用原生 SwiftUI、UIKit、WidgetKit，学校、学习通和快递在相应官方页面使用 WebKit。Android 使用 Vue、Capacitor 与 Kotlin 原生桥。双端共用社区服务及教务解析协议。

下表记录源码核对。运行验收以对应提交的 CI、截图与真机记录为准。

| 范围 | iPhone 实现及差异 | 验收重点 |
|---|---|---|
| 首页与导航 | 五个原生 Tab；浅色主色与 Android 一致（#6843B5）。小屏缩短头图，学习通、成绩并排，空课表提供操作入口。实时课程时段并列展示，课程时间线可折叠，学习入口在生活服务前。双钱包、地图、取件、待办、考试直达。首页离开或退到后台时停时钟 | 四角安全区，大字体，Tab 保留滚动位置 |

## 设计和验收规则

- 主导航固定五项。消息位于社区，统一日程在待办，荣誉展柜在我的和社区个人页。
- 姓名优先；官方身份和佩戴称号采用语义颜色与 SF Symbols。匿名内容不关联身份。普通按钮命中区至少 44 点，使用系统字号和安全区域。
- 收藏柜使用可自适应的列数、稀有度、图形和文字。隐藏条件只在解锁后展示。解锁通知不截获触控，系统减少动态设置优先。
- Android 更改一项功能时，对照本表更新源文件、iOS 实现、平台例外、账号条件、验收截图和未运行的验证。更改成就时运行 `node ios-native/Scripts/sync_medals.mjs` 并提交 JSON，CI 用 `--check` 检查目录漂移。
- 新增 Swift 文件后运行 `python3 ios-native/Scripts/generate_project.py`。双端教务脚本逐字节比对。不得用静态页面或演示成绩补齐截图。
- macOS 构建 iOS 15.4 设备目标；在同一 SDK 的两种 iPhone 尺寸运行界面验收。Android 对照任务使用固定 test.31 CI 已验证的 debug APK（产物过期时从固定源码重建），使用模拟器系统截图。两个端的截图按 home、schedule、community、tasks、profile、gallery 命名。社区未登录截图不证明真实收发或管理员业务成功。
- 并列检查控件层级、设备安全边距、遮挡、点击目标、可访问性与返回。校内认证、相机/支付、学习通验证码、系统输入法及真实网络属于设备验收。

运行含社区联调的全部 XCTest 前，在仓库根目录执行 `npm ci` 与 `node ios-native/Scripts/acceptance_community.mjs`。测试进程用独立 URLSession 将业务请求限定到 127.0.0.1 上的临时数据库。关闭进程即结束服务，正式 iPhone 客户端没有该路由。
