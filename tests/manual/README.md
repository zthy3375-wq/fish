# 手动浏览器场景（不进入生产构建）

启动 `npm run dev` 后，打开 `/tests/manual/scenario.html?scenario=six&theme=light`。

- `scenario=zero`：零课程、无后续课程。
- `scenario=one`：一节正在进行的课程，无后续课程。
- `scenario=six`：六节课程，已结束/正在进行/下一节，固定北京时间10:15。
- `scenario=long`：六节中英文长名称课程，详情保留全文。
- `theme=light` 或 `theme=dark`：仅修改开发源的本机主题偏好。

视口：360×800、390×844、430×932；分别检查浅色/深色、课程详情、滚动到底部、导航与内容边界、横向滚动条。主内容使用独立滚动区，应滚动 `main[aria-label="页面内容"]`，不是浏览器文档。

脚本仅替换此测试页面内存中的模拟 provider 与时钟，不修改生产教务数据、不进入 `dist`。它会改变开发源的本机主题，测试后可在个人设置中恢复。此轮云端浏览器连接失败，这些页面已准备但未完成实际渲染验证。
