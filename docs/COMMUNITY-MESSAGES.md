## 已实现

- “我的社区”与本人公开主页提供关注、粉丝统计和本人名单入口；进入个人页重新请求实际统计，失败显示未取得的状态并允许重试。
- 关注名单保留；新增粉丝名单、回关/取消关注、互相关注状态与游标分页。统计及名单仅对本人开放，调用者提交其他 memberId 不会读取他人关系网。
- 同学公开主页可发起独立一对一文字私信；互动消息和个人页可进入私信会话。匿名帖子/评论仍不提供公开作者 id 或私信入口。
- 会话列表显示昵称、头像、最后消息、未读数；历史消息分页；聊天页支持发送、失败重试、未读同步失败重试、新消息补齐、查看更早消息、屏蔽。
- 客户端轮询仅在前台进行，聊天页/未分页的会话列表约 8 秒刷新；社区总未读使用现有约 60 秒及回到前台/打开个人页刷新。仅应用内，不含系统推送、私信图片、群聊、撤回或对方已读回执。
- 未发送文字按会话保留在本次登录的内存中；普通返回可恢复，修改失败草稿生成新请求号，退出账号清除。不持久保存私信草稿或聊天正文到本机磁盘。

## 服务端协议

附加 schema 9，不改已有账号、帖子或匿名代号。新增 `hyt_dm_threads`、`hyt_dm_messages`、`hyt_dm_reads`，启用 RLS、撤销直接客户端访问；沿用唯一服务端 RPC。

- `follows.stats`、`followers.list`：本人统计和粉丝名单；现有 `follows.list` 与 `follows.set` 保留。
- `messages.open/inbox/unread/list/send/read`：会话使用唯一规范化账号对，消息使用递增序号分页。鉴权后的请求仅允许两名参与者访问。
- 发送 requestId 对发送人唯一；相同内容重试返回原消息，修改内容或更换会话复用请求号返回冲突。最多 1000 字，禁言账号不能发送，每分钟/每天及新联系人数有限额。
- 已读以实际显示的消息序号递增确认，后到消息保留未读；增量刷新可连续取多页，避免 8 秒间隔中消息多于一页时遗漏。
- `members.block` 与帖子公开屏蔽共用账号屏蔽关系，双方会话及未读隐藏、后续发送拒绝，解除双向关注，保留匿名招募隔离。主动恢复屏蔽后可重新查看历史，关注关系不自动恢复。
- 注销账号会清除涉及该账号的双方私信历史、会话和阅读状态，注销确认已补充说明。
- 私信正文存储在社区服务端，客户端未声称端到端加密；登录账号和教务资料不进入对方可见的私信资料。
