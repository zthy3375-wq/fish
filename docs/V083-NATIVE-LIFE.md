## 胖乖

- 原生短信登录窗口，用户明确同意平台协议后才可发短信或登录；登录/注册共用官方接口，提示未注册账号可能被创建。60 秒冷却跨弹窗保留；不自动发短信，不解验证码或绕过平台验证。
- 只连接固定 HTTPS userapi.qiekj.com，拒绝重定向，限制响应大小，固定端点列表，不提供任意 HTTP 代理。
- 登录返回后调用 user/info 校验账户 ID 和完整手机号。通过后才保存到独立 Android Keystore AES-GCM vault。取消/销毁通过代次与请求栅栏阻止迟到保存。
- 原生普通账户余额（元）、按商户分页的小票余额（点）、本金/赠送、最近20条消费。小票不除以100、不与现金相加；单位不明或字段缺失显示未知，不凭空显示0。
- 商户分页至完成或200条上限；缺页/重复/失败保留完整旧缓存。三个模块各有更新时间；登录失效停止后续请求。跨账号不继承缓存。
- 原生相机扫描NQT/SN，只解析核验域名/路径的二维码，不访问二维码URL。再次读取并核对设备ID与类别，展示运营商、程序、报价及可用性。
- 本轮扫码是设备识别与信息读取，**没有**设备启动、下单、余额扣款、结束用水或洗衣完成提醒。饮水、洗衣的交易恢复与启动结果核对仍是后续独立工作，不以仅得到SKU冒充已接通使用。
- 商户钱包点击充值时先确认本机账户/商户，再定向打开支付宝官方商户充值页，不再要求用户自己从钱包首页找商户。收银与支付仍由平台执行；未实现应用内建充值订单/Alipay SDK付款。返回只触发余额核对，不报告到账成功。
- 官方网页保留在帮助入口；日常余额/消费界面不加载第三方广告网页。网页会话与原生登录相互独立。

## 地图

应用自己的 Leaflet 地图，非 iframe。默认随包离线道路/建筑轮廓；按需在线OSM底图、东/西校区切换、分类搜索、地点收藏、长按/点击选点、个人地点增删和JSON导入导出。个人地点上限100个；导入检查地理范围和类型，保留原有地点。备份不含账户数据。

地图中心与轮廓依据2026-11-08公开OSM数据：relation/21262225（邯郸学院），way/226564123（图源仍标原河北工程大学），及周边道路/建筑。校区地址与近期学校活动页面交叉核对：[学校就业信息](https://hdjy.hdc.edu.cn/jobfair)、[西校区双选会](https://hdjy.hdc.edu.cn/largefairs/view/id/9436/domain/hdc)。图源二教、三教、看台等名称可能已变更，界面标为“图源旧称·待核对”；不冒充精确校门或最新楼宇地图。尚无可靠的本校驿站/宿舍等精确坐标，不自行编造。

地图坐标保持 WGS84；步行路线交给 OSM 查询，不将这些坐标错误当作 GCJ-02，也不画一条直线假装校内最短路径。在线瓦片使用官方tile URL、默认浏览器HTTP缓存、可见署名和应用User-Agent，不预下载瓦片；默认离线几何图是ODbL地理数据，不是瓦片缓存。
