# 当前开发状态 · v0.8.0

用户在 v0.7.3 后反馈“可以了”，本轮按确认方案重构使用流程，不修改 Kotlin 登录与同步协议。

- 主导航改为今天、课表、待办、学习、我的。旧 agenda 深链接归一到待办。
- 待办默认今天、接下来、未安排；已完成、截止、来源、课程等位于筛选。提醒与备份移到我的。
- 共用任务详情，标题即可添加。日期计划使用可选 plannedDay，已有 plannedAt 数据保留；无具体时间时不产生开始提醒。重复任务、备份及学习通规划兼容新字段。
- 学习通按课程查看，默认待提交；同步管理在关注课程选择后收起。一次点击安排今天，不修改平台截止与提交状态。个人“已做完”独立于“已提交”。
- 今天页直接处理个人任务，展示同一份学习通规划和临近截止；来源存储保持独立。
- 原有学校课表、成绩、个人任务备份、平台会话存储键不变。APK 测试包仍采用独立包名 org.handancampus.app.learning.v080，不能冒充覆盖升级：旧应用保留，新安装需重新连接账号，个人待办可通过备份恢复。

验证：本地领域测试与移动端交互回归、Android 构建以本轮 PR 检查记录为准。移动端自动化使用人工数据，不代表真实账号全量同步或通知后台行为通过。

开发分支 feature/daily-flow-v080 基于 feature/learning-reliability-v073。固定发布签名、平台页面兼容、课程内断点、考试通知独立调度仍待处理；本轮不声称已解决。
