# 当前开发状态 · v0.8.4 地图资料与教室目录

新增从官方教务页面逐页核对的 965 条场地记录、29 个楼栋/场地区域，含教室、实验室及室外场地。按楼栋明确的东西区名称归属；18 条缺失楼层保持未知。查询是特定时段空闲场地，不声称全校完整目录。只保存名称、编号、类别、楼栋、楼层、座位及原始校区，没有身份凭证、管理员或使用班级。
