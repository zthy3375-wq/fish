# 当前开发状态 · v0.8.7 竖屏二维码识别

用户确认饮水机的问题为相机持续无法识别。新照片离线读出与之前一致的 SN 格式，现有 URL 解析支持该格式。旧版直接调用 ZXing 默认 CaptureActivity，库默认横屏；现在指定自己的 portrait Activity，并锁定竖屏，取景区域为方形。连续对焦、重新对焦和手动手电；默认不自动开灯，避免屏幕反光。
