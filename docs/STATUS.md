# 当前开发状态 · v0.8.7 竖屏二维码识别

用户确认饮水机的问题为相机持续无法识别。新照片离线读出与之前一致的 SN 格式，现有 URL 解析支持该格式。旧版直接调用 ZXing 默认 CaptureActivity，库默认横屏；现在指定自己的 portrait Activity，并锁定竖屏，取景区域为方形。连续对焦、重新对焦和手动手电；默认不自动开灯，避免屏幕反光。

实时解码仅尝试 QR，使用ZXing-C++ 2.3.0并保留Java解码回退，交替使用原始和5×5高斯柔化灰度帧；增加本地相册识别，针对蓝色LCD码尝试独立颜色通道和柔化。系统文件选择器不索取全相册权限；照片按边界缩放到不超过200万像素，仅本机内存识别、不上传、不写日志、不保存原始二维码。识别结果仍经原有域名/设备码校验，扫码与相册识别均不付款。

实际用户照片使用同版本ZXing-C++ 2.3.0和5×5高斯核离线识别成功，原Java解码器直接与预处理后均未成功。照片与设备编号不入库。新增蓝色屏幕、普通印刷、反色、空白和图像上限原生回归。实际相机自动对焦、反光和距离效果仍待用户手机确认。饮水启停/结算未实现，洗衣、地图和其他模块保持现状。
