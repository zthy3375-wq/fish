# 统一日程与个人待办

当前分支叠加成绩分析分支，PR目标为feature/grade-analysis-v060，保持分轮审查，不合并main。

## 已实现

- 首页“日程与待办”和教务“统一日程”使用同一页面，不增加底部Tab。
- 按北京时间汇总对应学期课程、学校已缓存考试与个人待办，支持日期、当天/未来7天和类型筛选。
- 学校课程沿用各自学期的周历，个人课程沿用所属学期，避免把不同学期统一套用同一教学周。
- 考试时间不能解析时保留原文并显示待核对，不生成虚假的00:00。缺少考试日期时计数提示，原始考试仍可在考试安排查看。
- 个人待办可新增、编辑、标记完成、恢复、删除，支持课程关联、备注、可选截止时间和提前提醒。逾期与未设截止时间的待办独立展示。
- 学校连接失效仍展示缓存，个人待办不因学校登录、退出或同步而删除。任务编辑草稿和筛选在本次运行跨Tab保留。
- 独立版本化JSON待办备份；恢复只添加缺失项，不覆盖本机已有项、不自动开启通知。原有课表备份格式保持兼容，待办备份与其分开。

## 存储和提醒

个人待办使用handan.personal.tasks.v1 / Capacitor Preferences，不与学校缓存或个人课表存储键混用。写入串行化，Web可用时使用Web Locks。验证失败/读写失败保留原数据，不把损坏数据当空数组覆盖。

提醒默认关闭，用户主动开启后才请求系统通知权限。学校数据不提交给第三方；提醒由Android本地通知处理。待办通知使用410000–410029与handan-task标识，只撤销自身通知，保留课程通知300000段。仅调度未来未完成且有截止时间的待办，最多30条；启动/前台恢复/修改时续排。权限拒绝或调度失败不影响待办保存。锁屏、省电和重启后的实际送达仍待真机验证。

## 范围

本轮提供可实际使用的个人待办和已有课程/考试统一日程，不声称已接入学习平台作业、自动签到、教学评价或选课数据。学习平台接入仍需核对用户使用的平台及官方会话。

课程日期依赖对应学期的本机日历配置；不把它标称已验证的官方校历。学校会话和课程/成绩/考试请求逻辑不改动，日程筛选不新增学校请求。

## 检查与安装

算法覆盖北京时间、UTC跨日、日期边界、教学周、重复安排、未知考试时间、逾期/无日期待办、备份和通知限额。存储测试覆盖并发、失败写入、损坏数据保护与删除；通知测试覆盖权限、插件错误和与课程通知隔离。浏览器检查使用明确人工样本，不作为学校账号证据。

Android versionCode64 / 0.6.1-agenda-test。另构建org.handancampus.app.agenda.v061“邯郸校园·日程测试”并行包，保留旧App与数据，首次在本包官方页登录即可读取本人学校数据。普通包保留原应用标识；CI临时签名不等同正式升级签名。

手机测试：打开统一日程→新增个人待办→设定截止时间→标记完成/恢复→关闭重开→核对待办保留→主动开启提醒并验证实际送达。学校数据日程与真实考试日期、后台提醒、文件分享/恢复仍需本人设备验证。
