# 社区互动消息与讨论回访 · test.7

本轮基于 `51df592`，开发分支 `feat/community-return-20261116`。Android 测试版本 1.3.0-test.7 /157；iOS 同步原生 SwiftUI 实现。正式更新保持 1.2.4 /150。没有发布蒲公英、修改正式更新元数据或合并 main。

## 实际行为

- 底部为首页、课表、社区、待办、我的。社区列表保留主导航，详情、发帖和账号操作收起主导航。
- 回复、收到的赞和关注讨论的新回复进入互动消息。点消息直接定位根评论/对应楼中楼；返回保留列表位置。消息已读在服务器保存，只标记打开或用户明确选中的消息。
- “我参与的”聚合发过帖/评论过的讨论；“关注的讨论”可取消。发帖或回复后默认关注，主动取消后继续回复不会偷偷恢复。
- 公开作者可打开主页，展示昵称、简介和公开帖子；匿名内容、收藏、账号登录名不进入公开主页。点赞消息使用泛化身份，避免通过通知关联匿名作者。
- 列表文字与留白打开帖子，图片直接查看大图，头像/昵称打开公开主页。三个区域有各自明确动作。
- 轮询只在社区活跃且应用可见时进行，每 60 秒检查互动；这版没有接入系统推送、@ 提及或私信。

## 数据与兼容

迁移为 schema 3，新增通知、关注讨论和阅读位置三张表，以及成员简介。帖子/评论保留原表和原 ID；迁移可重复执行。通知与评论写入同一事务，重试不产生重复提醒。通知游标保留数据库微秒精度。隐藏、删除、屏蔽及注销后的内容不会继续出现在未读数/通知摘要。

旧后端没有 `engagementEnabled` 时客户端隐藏新入口，保留原有浏览发布功能。启用新功能需要先有 schema 3 服务；只安装新 APK 不会升级服务器。部署脚本已加入真实接口冒烟检查，但服务启用是单独操作，不随编译/PR 运行自动发布。

所有演示账号、内容与图片仅在 tests/fixtures 或本地测试数据库；离线 HTML 预览不访问线上服务。
