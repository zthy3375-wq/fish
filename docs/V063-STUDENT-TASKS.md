# v0.6.3 学生任务与日程

## 分支与范围

基于PR #14最新开发提交f0e83ef，继承PR #12成绩分析、#13统一日程与个人待办；新分支feature/student-tasks-v063，独立Draft PR，未合并main。仅Android；不接入学习通，不恢复空闲教室。学校客户端、认证、教务请求契约及学校缓存未改动。

## 使用流程

- 任务清单：今天、收件箱、计划、即将截止、已完成，搜索课程/标题/备注，按截止、优先级、标题排序，可置顶、按课程筛选和分组。
- 底部快速输入只需标题；在“今天”添加会安排到当前北京时间，其他清单进入未安排的收件箱。详情中修改执行计划、5—1440分钟时长、最终截止、四档优先级、步骤和备注。
- 已过期的截止保持原日期，“今天做/明天做”只重排执行计划。今日清单包含未完成的以前计划与已到期任务，避免消失；截止统计包含未来7天和逾期项。
- 日程时间轴与任务清单共用同一存储，分别展示学校课程/考试、个人计划和任务截止。当天、未来7天、本周及日期跳转；学校事件只读。跨日计划以开始日显示时长，不伪造课程和考试。
- 模板：作业、实验报告、考试复习、论文、报名、个人事务；模板只提供用户编辑的个人任务，不冒充学校作业。课程选择来自已缓存课表；旧任务关联课程名称保留。
- 详情支持鼠标右键/原生长按上下文入口及显式操作按钮；未实现容易误触的滑动删除。系统返回、浏览器返回与Escape优先处理详情和放弃修改确认；详情有焦点约束，底层页面与导航暂时inert。

## 重复语义

每天、工作日（周一至五，不解释法定调休）、每周、指定星期、每N天。以计划开始为基准；没有计划时使用截止时间。完成时保留本次记录，仅生成下一次未来发生项，跳过已错过的周期，避免积累大量历史欠账。计划与截止的间隔保持，步骤重置。不会提前向时间轴填充未生成的多周重复项。

撤销本次完成时，删除尚未修改的下一次发生项；如果下一次已修改或完成，阻止撤销并说明原因，避免破坏后续工作。删除当前项不会级联删除其他已生成的独立发生项。

## 数据安全

`handan.personal.tasks.v1`只读保留。首次没有v2时校验旧快照，并写入`handan.personal.tasks.v2`；写入失败或原始数据损坏会停止迁移，不写空数据替代。版本、完成状态、原提醒开关与提前提醒均迁移；不依赖学校会话。

写操作串行化，支持Web Locks时跨标签页加锁。旧v1和新v2 JSON备份均可合并恢复；已有ID保持本机记录，提醒开关不由备份开启。最多500项（含完成历史）、每项50步骤、5条自定义提醒。超限返回错误并保留原快照，不截断任务。编辑保存带原修订时间检查，防止通知完成等并发修改被旧详情覆盖。

任务清单模式、智能清单、搜索、课程筛选、排序、快速输入草稿和时间轴日期/范围在独立Preferences键中恢复。打开但未保存的完整详情不跨进程持久化；页面切换时通过返回守卫处理，勿把未保存编辑视为已保存任务。

## Android提醒

复用已有Capacitor LocalNotifications原生插件，不新增账号或第三方服务。支持计划前、截止前、自定义绝对时间，最多5次；另有稍后10分钟提醒。全局开关默认关闭，仅主动开启时请求权限。按最近30个未来提醒调度，打开App/前台/变更后续排；系统节电可能影响准时性。

任务通知范围410000—410029，课程范围保持300000—300059；只取消任务通知。通知操作“完成”和“10分钟后提醒”通过原生事件回调持久化，通知中携带任务ID与修订号，旧通知不能直接完成已改动的任务。快捷操作需要Android启动/恢复应用执行，未声明可在终止进程中无界运行。

通知失败不回滚已经保存的任务。相对提醒缺少对应计划/截止时不调度；界面明确说明。锁屏、节电、重启后的真实送达和动作回调待真机验证。
