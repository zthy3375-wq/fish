## 限制

未完成 Android/iOS 真机、Safari/WebKit、系统状态栏/手势导航区域、后台恢复、屏幕阅读器或商店签名测试。帧率没有仪器实测；仅采用低成本 CSS 动效与 prefers-reduced-motion 降低风险，不承诺具体 FPS。

本版本不包含学校登录、真实数据同步、离线 Service Worker、系统推送或远端数据缓存。应用内提醒是本地演示；本机设置可以重置；网络不可用时首次加载仍需托管资源。不应将演示教学周与校历用于真实教学。
