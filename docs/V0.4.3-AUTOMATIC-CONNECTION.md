# v0.4.3 自动连接测试

> 历史记录：本文描述对应版本开发时点；当前功能和最新真机反馈以 [STATUS.md](STATUS.md) 为准。

从 v0.4.2.1 的独立测试分支继续开发，不合并 main、不发布正式站点。

进入原教务连接测试页，确认当前学年、学期和第一教学周正确，选择“登录后自动连接 / 刷新学校课表”。在学校真正网页自行登录；应用会在限定校方域名内尝试跟随页面里现有且唯一的学生课表菜单链接，并有界等待课表加载。不猜测接口、不绕过验证码，不读取登录表单或提取凭据。

识别到完整课程后自动读取；采用用户提供的邯郸学院13节40分钟作息。只有实际课表文档的 xnm/xqm 下拉选择值与本机学期匹配时自动保存，否则展示预览要求核对一次。学校的 DOM/菜单结构尚未在新自动模式下真机验证，若菜单不符合识别条件仍需在学校页面打开课表，但不必再点检测/读取按钮。90轮有界检测后可手动处理，不宣称所有账号已通过。

首次保存创建独立学校学期；后续刷新只替换当前绑定学校学期，不新建重复分区，不覆盖个人学期。课程按内容而非数组下标匹配保留ID，新增/取消体现在学校分区的完整更新；空表、错误或冲突不覆盖上次数据。成绩和考试仍是原有演示，不声称真实接入。

本期仍不保存会话凭据，关闭窗口后下次可能需要重新登录；不是免登录或后台同步。当前试验构建只供本人测试，不向普通学生正式开放。原手动预览路径继续保留用于学期不明或解析异常。
