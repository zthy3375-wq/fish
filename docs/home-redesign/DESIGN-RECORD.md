# 首页改版设计记录 · 2026-11-17

本轮为现有浅紫白体系内的 Android 首页布局改版。保留系统字体、宋体横幅、小金鱼、校园图片、主题选择和首页／课表／社区／待办／我的五 Tab；没有建立新品牌或新增全局 token。设计方向见 [BRIEF.md](BRIEF.md)，独立审查结论见 [FINISH-REVIEW.md](FINISH-REVIEW.md)：`disposition: ship`，范围为首页浏览器呈现与代码。

## 已落地的构成

| 区域 | 当前实现与设计意图 |
| --- | --- |
| 校园横幅 | 基础高度 224px 加顶部安全区域；保留原校园图片、宋体品牌、日期、通知和小鱼入口。小鱼沿用减少动态、滚动、后台与弹层暂停逻辑。 |
| 课程速览 | 横幅后首先展示当前或下一节课；开始／结束时刻与课程名称、地点、教师并排，数字等宽。课程整块进入详情，跨日日期保留。课程组为 16px 外圆角、细边界和淡紫重点面，无静态投影。 |
| 今日时间线 | 默认折叠，按钮通过点击及键盘 Enter／Space 展开；保留 aria-expanded、aria-controls、动态进度、已进行／剩余时长和课程详情。展开及查看课表入口至少 44px 高。 |
| 学习入口 | 学习通、成绩与学业仍属于课程组，底部双列，入口至少 48px 高。 |
| 生活服务 | 趣智校园、胖乖生活采用同一白色组内的完整操作行，最小高度 72px、行圆角 0、外组圆角 16px；图标、用途、账户／余额状态与箭头共存。余额保留真实缓存、“上次查询”和过期提示。 |
| 组内工具 | 取快递、校园平面图位于生活服务组底部双列，最小高度 64px；窄屏说明自然换行。 |
| 今日计划 | 位于生活服务之后，沿用真实任务与空状态。原有按需统计提示保留在首页主内容内。 |

首页主内容左右 16px、顶部留白 14px、业务组间距 20px；这些均为本次首页局部参数。未连接学校的真实空状态通过主 Tab 导航进入“我的”连接学校；已连接或有课程时提供课表路径，不填入演示课程。钱包、扫码确认及官方跳转沿用原业务流程。

## 样式所有权与记录方式

`src/tokens.css` 持有共享语义 token；`src/product.css` 提供共享产品覆盖。`src/main.ts` 在 `product.css` 之后导入 `src/home-dashboard.css`，后者持有首页课程、分组间距、学习入口和今日计划的局部布局。`src/campus-home.css` 持有横幅；`src/components/LifeServices.vue` 的 scoped 样式持有完整服务行与双列工具。旧 `src/interface.css` 的首页服务 92px 高度和隐藏行尾箭头覆盖已去除，组件行圆角归零。

本次合并更新 `DESIGN.md` 中与首页实现冲突的段落，完整保留其 frontmatter 全局值和无关页面记录。`.impeccable/design.json` 保持 schemaVersion 2、已有颜色元信息、字体元信息、阴影、动效、断点和七个原组件；仅同步 Overview 镜像并增加两个标明首页局部范围的组件预览。预览使用自包含 HTML／CSS 和已有语义变量，静态内容只用于展示构成，不模拟真实查询或应用导航。未引入首页专属全局颜色、字体或尺寸 token。
