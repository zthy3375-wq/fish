# 首页改版 · 2026-11-17

模式Operate；对象为频繁短时打开应用的邯院学生。基于test.16与iOS16基线，保留五Tab、小金鱼、校园图片、所有接口、账户与存储。只调整安卓首页，不移植iOS或发布。

## 设计与交互

采用既有视觉体系：校园紫#6843b5、淡紫#eee8f8、白#ffffff、底色#f7f6fa、正文#262233、边界#e3dfeb。宋体只保留给校园横幅品牌，业务用系统无衬线，时间与金额使用等宽数字。复用原图和原小鱼，不新增外部字体或图片。

首屏顺序为校园横幅、课程速览、生活服务、今日计划。课程区以开始/结束时刻与课程/地点并排形成可扫描的课时记录；明确区分上课中和下一节。今日时间线默认折叠，点击或键盘可展开，保留动态进度与课程详情。学习通与成绩保留同组的两个入口。无课程时提供真实连接/课表路径，不填充示例课程。

生活服务由分散彩色金额卡改为同一组完整操作行：趣智/胖乖保留真实缓存余额和过期提示，辅以查询语义；取快递/地图位于组内下方。金额不再抢占页面主层级。每个操作至少44px，使用原钱包、扫码确认和官方跳转，不新增支付或自动扫码副作用。

小鱼是唯一持续品牌动效，保留减少动态、滚动暂停、后台暂停；时间线只给展开箭头短过渡。课程/服务采用16px圆角和一条边界，不叠加阴影。保留原主题选择、安全区域及键盘逻辑。

## 验证与交付约定

相同合成数据、相同视口对比test.16与test.17。检查360/390/430px的课程详情、时间线展开/收起、钱包与扫码、学校读取、课表、待办、导航；另检查深色与安全区域。合成图不充当真实账号/支付验收。

当前工作环境Chromium因socket权限限制无法启动，浏览器与截图交由CI执行；本地执行单元、协议、类型和生产构建。Android包需构建、签名/身份、内嵌网页核对后交付；实体安装和真实服务仍单独说明。
