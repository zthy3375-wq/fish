# 邯院通社区荣誉

社区广场进入「荣誉殿堂」，个人主页进入「荣誉收藏」。殿堂的历史贡献档案沿用已有「社区贡献者」授予日期。收藏展示获得日期、稀有度、事迹和当前佩戴。Android 中原有社区成就仍可通过收藏顶部进入。开发者从「我的社区」进入荣誉管理，管理员继续用原权限处理社区内容。各客户端依据服务端能力显示入口。

## Android test.36 收藏结构

「荣誉」列出开发者和管理员，以及种子用户、优质创作者、社区贡献者、初代居民、邯院之光和四类年度可佩戴荣誉。帖子和评论的署名只容纳一个官方身份标识和一枚自选荣誉。年度荣誉佩戴时带年份，退役的「校园传奇」「传说中的那个人」按原授予记录进入绝版档案。

「社区成就」合计 31 类，包含原有十项社区和时光成就、十项由旧称号整理出的里程碑、六项隐藏成就、两类季节纪念及三项新成就。个人主页可混合展示最多三枚新旧成就。隐藏成就尚未发现时只显示剪影，公开后可加入展示，恢复私密时会自动撤下。

「第一次上墙」由开发者按首篇作品的精选凭据审核。已有「三次上墙」可补领，获奖时间为补领日。「一百个赞」分别核算各篇公开帖的有效不同点赞者。「写满这一页」合计十五项不同的常规成就，跳过隐藏、季节和本项。原定义、授予和佩戴记录的键值保留，标题和分类由展示投影整理。

## 数据与发放

- 迁移在单一事务中增加三张表、四个成员字段及相应索引。保留原客户端响应、账号、会话、帖子、回复和历史授予。部署前后比较原有列和数据。
- 满足自动条件的历史账号在打开个人收藏时补发。每个账号最多每 20 分钟评估一次。每次进入收藏仅批量读取一页，公开帖子、评论继续沿用当前作者投影。
- 年度以中国标准时间计算。当前年可以审核发放和提前封存，往届自动绝版，已获得的历史荣誉继续可查。数据库事务内检查容量并保存经手人、依据、事迹和请求编号。撤销保留独立管理记录。
- 公共档案包含公开事迹和年度、授予状态。审核依据和异常记录保留在开发者工具。取消公开隐藏荣誉会同步移除其佩戴，匿名内容保留原作者隐藏策略。
- Android 的社区设置支持「减少动画」，系统的减少动画设置也会生效。iOS 读取系统「减弱动态效果」。
