# 邯院通社区荣誉

社区广场进入「荣誉殿堂」，个人主页进入「荣誉收藏」。殿堂的历史贡献档案沿用已有「社区贡献者」授予日期。收藏展示获得日期、稀有度、事迹和当前佩戴。Android 中原有社区成就仍可通过收藏顶部进入。开发者从「我的社区」进入荣誉管理，管理员继续用原权限处理社区内容。各客户端依据服务端能力显示入口。

## 荣誉清单

| 分类 | 荣誉 | 发放依据 |
| --- | --- | --- |
| 复用身份 | 开发者、管理员、种子用户、优质创作者、社区贡献者 | 原账号角色及原有授予记录 |
| 复用成就 | 原社区成就、时光成就和全局收藏馆 | 原有记录、解锁规则和展示设置 |
| 传说 | 邯院之光、传说中的那个人、镇站之宝、校园传奇 | 审核真实贡献、原帖、长期影响或公开授权 |
| 传说 | 开天辟地 | 原始注册时间和账号 ID 决胜顺序，前 100 个注册账号 |
| 史诗 | 社区建筑师、黄金创作者、捉虫大师 | 审核落地版本、官方精选或严重问题的修复凭据 |
| 史诗 | 神帖制造机 | 公开帖获得至少 10 名满足注册时长的独立账号点赞 |
| 稀有 | 初代居民 | 第一条社区注册记录起 30 天内加入 |
| 稀有 | 百事通、金牌摄影师、校园观察家、气氛组组长 | 审核跨时段互助、原创摄影精选、校园见闻和社区认可 |
| 年度限定 | 年度人物、年度最佳创作者、年度摄影师、年度最温暖的人、毕业季青春纪念章、迎新季引路人 | 按年份建立发行记录，核实评选、参与结果或实际贡献 |
| 隐藏 | 凌晨四点的邯院、被开发者看见了、世界线收束、考古学家、命运的相遇、没有人是一座孤岛 | 由服务端从既有社区记录判定。解锁后本人可查看名称和故事，可单独选择是否公开 |

## 数据与发放

- 迁移在单一事务中增加三张表、四个成员字段及相应索引。保留原客户端响应、账号、会话、帖子、回复和历史授予。部署前后比较原有列和数据。
- 满足自动条件的历史账号在打开个人收藏时补发。每个账号最多每 20 分钟评估一次。每次进入收藏仅批量读取一页，公开帖子、评论继续沿用当前作者投影。
- 年度以中国标准时间计算。当前年可以审核发放和提前封存，往届自动绝版，已获得的历史荣誉继续可查。数据库事务内检查容量并保存经手人、依据、事迹和请求编号。撤销保留独立管理记录。
- 公共档案包含公开事迹和年度、授予状态。审核依据和异常记录保留在开发者工具。取消公开隐藏荣誉会同步移除其佩戴，匿名内容保留原作者隐藏策略。
- Android 的社区设置支持「减少动画」，系统的减少动画设置也会生效。iOS 读取系统「减弱动态效果」。
