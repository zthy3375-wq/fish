# v0.6.0 成绩分析与学业中心

基于main 6a8014b开发，携带PR #11中已验证的Android范围清理，不合并main。原课表/考试/学校会话与个人备份继续保留；取消的功能不恢复。

## 入口与范围

教务→成绩分析，现有grades路由直接升级；分析概览与原始成绩明细共用筛选状态。学业中心在现有study路由展示学分分类、历年趋势、未通过课程及原学籍资料。移除教务页原来重复的快捷卡片，不增加底部Tab。

全部统计从handan.academic.cache.v050现有成绩缓存派生；点击图表、切换学期、搜索和排序不请求学校。页面可离线显示此前记录。仅主动刷新或原有自动同步会请求学校。筛选在应用本次运行期间跨Tab保留，退出学校账号重置；没有新建包含学生信息的持久存储。

## 数据模型与兼容

保留旧字段name/scoreText/credit/gpa/term/kind，并白名单保留可选courseCode、recordId、year、termCode、examType、passed。现有学校返回值缺失时保持为空，不通过课程名猜测补考/重修、绩点或类型。

原生只读成绩适配器从kch/cjbh/xnm/xqm/ksxzmc映射可选字段；这是兼容性字段映射，不表示已经在本次过期的云端会话中取得这些字段。手机刷新后的字段覆盖率与真实重修样本仍待验证。学校账号、Cookie、完整响应及个人成绩没有提交到仓库。

- 空学分/空绩点不再经Number('')变成0，负数或非有限值按缺失处理。
- 未公布的空cj保留为待公布，不丢弃整批成绩。
- 只有结构完整的分页结果才提交；学校声明的总记录数与实际返回不一致时保留旧成绩。
- 原有课表切学期不再把成绩请求限制在该学期。getGrades不传学期参数，查询学校当前可见全部记录；exams仍按原有学期查询。
- 新缓存记录scope=all，旧缓存/单学期缓存明确提示历史覆盖范围未确认。该标记代表查询范围，并不证明学校已发布全部课程。
- 异常、过期和意外空成绩响应不擦除上次非空成功快照或时间戳；新账号成功登录仍清空前一账号快照。

## 计算口径

- 数值成绩：仅完整的0–100数字（允许末尾“分”）；百分制均分不包含等级/通过制，不做字母或五级制换算。
- 优秀、良好、中等、及格、合格、通过按文字识别通过；不及格、不合格、不通过、未通过识别未通过。待公布/缓考等为待定；缺考、免修等未经确认的状态保持未知。学校显式通过标记与成绩矛盾时保持未知。
- 完全重复记录按白名单字段指纹折叠，原始不同成绩仍可展开查看。课程编号优先归组；缺少编号的同名多记录整体待核对，不擅自断定它们是同一门重修或不同门课程。
- 同一课程多次成绩：保留历史，不采用未验证的最高分/最后一次替代规则，这些组不参与均分和加权绩点。页面显示排除数量，避免隐瞒统计样本。
- 已获学分为可确认通过课程的学分去重参考。编号一致只累计一次；同名多记录无编号、学分冲突、缺失、未知或未公布不累计。跨学期分配到最早已确认通过的学期，不在每个重修学期重复累计。
- 算术平均为可确认课程的数值成绩平均；学分加权平均仅使用同时有正学分的数值成绩。
- 绩点只使用学校逐课程返回值，按这些课程的正学分加权。这是本地聚合，不是学校官方总GPA，不推导学校成绩→绩点公式。缺失值保留—，绝不补0。
- 同一编号的课程性质冲突时归入“性质待核对”，分类只分配一次学分；各类型学分之和与已确认学分一致，不重复归入必修和选修。
- 图表分布按去重成绩记录计数，分开标记百分制区间、等级/两级制、待公布和未识别。重修历史仍在记录分布中，可点开看到原始记录；课程数和学分则按上述去重口径。
- 趋势仅对可确定的学年学期排序；缺失学期/指标不填0、不跨缺口补线。未知学期记录仍在明细可见。

本地计算不替代学校学分认定、评奖、学位或毕业审核，不推断个人排名或毕业资格。

## 学校规则与培养方案调查

已阅读学校官方公开《普通全日制学生学籍管理办法》（政字〔2018〕57号）第十八条：课程一般按百分制、60分为及格；补考重修另按学业考核办法执行。第二十二条说明补考、重修应有标注。公开文件链接（站点检索标题误显示为防汛预案，但PDF正文为学籍办法）：
https://dept.hdc.edu.cn/filecenter/file/main%3A%3A5408bf1832064f46b5bf7f5ce48b61f2

该历史文件未提供足以确认当前本人适用绩点公式及重复成绩替代规则的材料，因此未编码这些公式。

已阅读学校《本科教育教学过程主要环节质量标准和质量保障办法（修订）》（党字〔2023〕36号）中培养方案质量标准：
https://dept.hdc.edu.cn/website-file/main%3A%3A44b6504db1bd43489e3aa27b6fc1bd57

文件中的165/160等是总体方案设计标准，不是学生本人的毕业要求，不能用作进度分母。本次恢复教务主页时已跳回官方登录页，云端会话已过期；尚未验证本人培养方案/毕业审核数据查询。学业中心显示“待接入”，不提供虚构进度条、剩余学分或完成百分比。
