# 校园小鱼首页

用户提供 1000017850.png 作为设计参考，并明确指定保留小鱼形象、四导航、去掉加号，重点使用趣智、胖乖和取快递。

布局：校园场景 → 当前/下一节课程与今日时间线 → 双余额卡与取件 → 今日任务 → 学习通/教务账号。地图为次要入口。课程名完整换行，时间线可横向滑动；钱包未知显示待查询而非零。卡片显示的是缓存余额而非实时承诺。

背景资产：public/art/campus-autumn.webp。使用内置图像生成工具，根据参考的淡紫天空、银杏、校园教学楼生成独立插画；无学校标识、文字或人物。生成后只做尺寸和 WebP 编码优化。提示词要点：3:2 校园插画；左侧留浅色天空供标题，右侧教学楼；下方书包、书、低墙及倒影；不包含 UI、文字、鱼。鱼单独用 SVG 绘制，在 CampusHero.vue 中保留黑色轮廓、圆眼及小旗。

动画用 CSS transform；IntersectionObserver 和页面/原生前后台状态控制播放，滚动暂停180毫秒，系统减少动态效果时停用，用户可手动暂停；卸载后清理监听和定时器。不遮挡账户或课程信息。

后端、统计授权、原生接水洗衣确认流程、数据键均不改动。发布至固定 buildKey 后必须实际下载核对 SHA-256，才允许更新腾讯云清单。不以提高最低支持版本来测试全体用户的强制更新。
