# v0.6.2 导航与页面状态收敛

本轮基于统一日程分支叠加，保留成绩分析、个人待办和既有教务能力。只选择性复用早期导航草稿的成熟导航/课表代码，未恢复已停止的平台或功能。

- 首页/课表/教务/我的为唯一一级导航，移除汉堡菜单、抽屉和其样式。
- Tab切换以replaceState发布路由，内部返回路径单独维护，避免堆积Tab历史。二级页返回原入口，旧academic/schedule地址归一到课表Tab，旧学校账号入口归一到我的。
- 一个浏览器边界拦截返回；Android继续使用原生backButton绑定，优先处理弹窗和未保存编辑确认，其次页面路径，根页退出行为保留。
- 移除页面out-in卸载动画，避免快速切换时旧页面仍可被点击。保留轻量淡入和减少动态效果支持。
- 各页面滚动位置按路由在本次运行中保存；课表周次、星期、日/周视图按学期保存。成绩筛选和待办草稿使用各自已有状态，不重新创建存储。
- 课表顶部三个大按钮移除，添加事项使用右上角＋。学校连接、个人课表和备份集中于我的。教务采用单一功能列表，包含成绩分析、考试、学业、统一日程和校历。
- 同步状态收紧，失败详情折叠展示；数据仍保留原有每模块状态。学校登录、会话、数据请求和存储契约未改动。

检查包含导航栈/浏览器边界、原入口返回、弹窗守卫和课表卸载恢复；移动端完整回归继续覆盖成绩分析、日程待办、重新加载与学校退出。Android资源同步、原生测试和APK构建以PR CI为准。实际Android手势返回、系统键盘与长期缓存仍待本人设备验证。
