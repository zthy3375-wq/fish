# 学校课程按周调整

## 使用方式

在首页、课表或日程点开学校课程，选择 **调整时间/地点**。可改星期、节次或自定义时间，以及教室。生效范围可选某一周、从某周起、全部上课周、自选周次；只选择原课程实际有课的周，单双周不会自动变成每周。

保存前会检查与其他课程的时间重叠，冲突需要明确确认。在课程详情可 **恢复学校安排**；这会恢复该项上课安排所有周次，不影响同一门课的其他安排或其他课程。将特定周改回原时间和地点，会只恢复这些周。

## 保存与同步

- 学校原始响应保持原样，调整保存在本机学校缓存内，不提交教务系统。个人课表、个人备份与调课记录分别处理。
- 调整按账号会话、学期、原上课安排与周次隔离；普通刷新、离线重开和切换学期后返回保留记录。
- 退出或重新连接学校账号会重置学校缓存和调课记录；个人备份不包含学校会话与调课。界面已说明此边界。
- 原安排的课程名、教师、时间或教室变更，或该周已不再上课时，旧调整暂停，显示学校最新安排并提示核对。无法唯一对应的重复安排不自动匹配。
- Android 本机编辑、学校同步和退出共用存储队列，迟到响应不会覆盖新编辑；iOS 保持主线程存储事务，写入成功后更新界面。
- 首页、课表、日程和小组件读取调整后的课程。现有学校课程不自动创建系统通知，个人课程通知规则不变。
