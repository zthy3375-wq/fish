## 使用

教务 → 管理个人课表 / 右上角导入。先在“学期”核对学年、开学日期、第一周周一、教学周数量。可建立多个学期，切换学期不会删除其他学期课程。

“课程”可手动创建、编辑课程，添加多个上课安排；每个安排独立设置星期、地点、起止节次与时间、每周/单双周/自定义周。可确认删除一个安排或整门课程。时间冲突需明确勾选保留；完全重复记录不能重复保存。保存成功后进入个人课表模式。可切回演示，个人课程仍保存，演示课程不会复制到个人数据库。

首页、日课表和周课表共享当前学期课程与教学周算法。所有课程时间均为北京时间。尚未上课、正在上课、已结束按实际时间计算；下一节课程不重复已过期学期。七列周视图显示课程摘要，点开查看完整名称与时间，左右滑动或周选择器切换教学周。

## 导入

- CSV：UTF-8 编码，逗号分隔。可下载标准模板，用 Excel 编辑后导出 UTF-8 CSV。每行一个安排。
- XLSX：一个工作表，首行列名，每行一个安排。使用纯文本时间 HH:mm；公式、图片、PDF、合并单元格周课表、旧 XLS 不支持。解析库按需加载。
- 必填映射：课程名称、星期、开始时间、结束时间、教学周。支持中文常用列名及 name/day/start/end/teacher/room/weeks 等英文别名；未识别时手动映射。节次没有提供则留空并提示，绝不推测钟点与节次对应关系。
- 星期：1–7 或一至日；周次：1-18、1,3,5 等，另有单双周列。结束时间必须晚于开始时间；不支持跨午夜单个安排。
- ICS：定时 VEVENT，DTSTART/DTEND，RRULE、RDATE、EXDATE；按具体日期还原到当前学期自定义周。UTC 转北京时间，Asia/Shanghai 与无时区时间按北京时间处理；其他时区拒绝。全天事件、跨日事件、DURATION 和 RECURRENCE-ID 改期例外拒绝，需先拆成独立事件。ICS 无标准教师/节次字段，留空并明确提示。
- 单文件上限 5 MB，表格 3000 行、50 列，ICS 最多500个事件并限制递归展开次数。XLSX 在完整解析前先流式检查压缩包，单条目解压8 MB、总解压20 MB、最多500条目，并拒绝路径穿越。存在任何错误则阻止整批提交，不静默跳过错误行。完全重复记录在预览中明确计数后跳过。时间冲突可明确确认保留。
- 先预览数量、课程、缺失字段与冲突，再合并或替换当前学期；替换有额外确认与导出备份入口。取消不会修改课表。相同课程名称/教师/备注可合并多个安排。

## 本地数据

Web 使用 IndexedDB 原子快照；Android/iOS 使用 Capacitor Preferences（SharedPreferences/UserDefaults），适合当前小型本地课表。不上传文件和课程。保存成功后再更新 UI；失败显示错误并保留原快照。Web 安全环境使用 Web Locks 串行写入，重新获得前台时重新读取本地数据、校准北京时间并续排提醒。大量课表或高频并发编辑场景后续可迁移 SQLite。

新课表结构版本为 1：ScheduleState → semesters / courses → arrangements。读取和恢复都完整验证版本、ID、字段和范围。未知版本拒绝打开且不覆盖，未来迁移必须显式增加迁移步骤。v0.2.1 没有个人课表数据库，无真实课程需要迁移；旧 `handan-campus.preferences.v1` 键原样保留，昵称、专业、主题、紧凑设置不受影响。

“数据”导出带格式标识、版本号和时间戳的 JSON，跨三平台恢复；恢复覆盖课表前需确认并可先备份，恢复后提醒默认关闭。清空当前学期/所有课表要选择操作并输入完整确认文字，保留个人偏好。卸载 App、清除站点数据、浏览器自动回收存储可能丢失数据，必须自行保管备份。原生导出走系统分享面板，由用户选择保存目的地。

Web 生产构建生成 Service Worker，首次联网安装成功后缓存应用资源（包括本机导入解析器），供断网启动；开发 HTTP 预览可能不支持 SW。数据页显示实际缓存准备状态。原生使用包内资源离线运行。尚未进行飞行模式断网重启端到端验证。

## 提醒

仅原生使用 Capacitor Local Notifications；Web 明确不支持可靠后台提醒。可开关、提前 5/10/15/30 分钟或自定义 1–120 分钟。仅个人当前学期排期，删除/编辑/切换后取消旧提醒再重排，忽略已过期提醒；最多排近期 60 条，打开/恢复前台时续排。只取消本应用课程提醒。

首次主动开启时请求通知权限；拒绝状态明确显示。Android 提供精确闹钟设置入口，未授权可能延迟；重启、省电、勿扰和系统额度仍可能限制送达。iOS 通知与后台限制需要真机验证。连续长时间不打开 App 时，60 条用尽不会自动永久续排。尚未完成真机通知、重启、时区变更、系统返回和系统文件选择验证。
