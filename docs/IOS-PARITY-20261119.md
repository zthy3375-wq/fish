# 2026-11-19 iPhone 五栏原生版验收

## 版本与产物

Android 对照采用 test.31（49dd6a6）的正常安装包。iOS 产品提交为 6d992a5，后续 7cfe0ff 仅调整键盘输入和 Android 冷启动截图的测试等待。两者的主程序、扩展和 Xcode 工程相同。iPhone Release 版本 0.1.0 (1)，主程序与小组件均为 arm64，最低支持 iOS 15.4。设备包需开发签名。模拟器包包含 arm64 和 x86_64，可在装有对应 iOS 运行时的 Mac 上安装。

## 运行结果

| 范围 | 已验证的行为 |
|---|---|
| 五栏与收藏馆 | iPhone SE（第三代）和 iPhone 16 Pro Max，iOS 18.5。依次进入首页、课表、社区、待办、我的，访问荣誉殿堂，切换隐藏分类，重启后重新读取收藏。 |
| 社区 | Swift 客户端通过真实 RPC 与临时数据库注册两个账号，重登同一账号、发帖、评论、重复点赞、读取荣誉、拦截普通账号的管理请求、校验重复私信与收件人消息。独立 HTTP 检查另验证了已读回执。 |
| 原生回归 | 384 项中 383 项通过，实体设备数据保护检查在模拟器跳过。待办覆盖创建、保存、取消修改、重启和完成。另验证学校连接入口、打断编辑、个人学期、深浅色、备份、学习通及两个钱包的未登录页面。 |
| 共享业务 | 534 项 Web 回归、126 项隔离社区服务端回归通过。教务协议 5 个、学习通解析 34 个、快递 DOM 解析 39 个样本通过。学校样本与模拟器测试均没有使用真实学生凭据。 |

在首次小屏截图里，点展柜标题误开了第一枚成就。修正后标题进入收藏馆，单枚展品进入相应详情。缩短首页头图，学习通与成绩并排，小屏可在首屏看到两个生活钱包。七个分类会依宽度换行，隐藏分类在小屏可直接点选。浅色主色及表面、文字、分隔色按 Android 语义色核对，继续支持系统深色及增强对比度。

收藏目录共 32 项（含 8 个隐藏彩蛋），其中 16 项设备成就、5 项教务成就、1 项学习通成就、10 项社区成就。私人教务与学习通按作用域存储。社区身份、可公开佩戴的成就和权限仍由现有服务端确认。本轮没有新增数据库表、定时任务或行为采集。实际生产点数没有测量。

## 待真机和后续版本验收

- 学校和学习通真实登录与验证码、非空成绩/考试、系统日历写入，需本人授权账号验证。
- 校园扫码、第三方 App 返回、真实出水和扣费、相机/通知授权、物理触觉、小组件和锁屏数据保护，需实体设备及相应现场条件。
- 本次核对到 Android 1.3.0（184）在 test.31 后继续调整了个人页的常用教务、右上角设置、学校状态展开、QQ 交流群快捷入口和删除评论的显示。iOS 已有教务、设置及帮助里的群号。本轮截图按 test.31 验收，后续差异单列跟踪。
- iPhone 采用可横滑的周时间轴显示相撞课程。Android 使用同屏多日网格。这是目前仍可看出的界面差别。
