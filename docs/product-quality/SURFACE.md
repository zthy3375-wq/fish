# Android 页面优化约定

模式：Operate。读者为使用手机的邯院学生。按现有功能结构优化，保持五 Tab、二级页面、中文语义和已有品牌。

## Direction contract
THESIS：减少跨模块视觉漂移，让查课、处理作业和社区阅读保持同一种操作语言。
OWN-WORLD：白色阅读面、低饱和紫色背景、清晰正文与辅助文字；小金鱼与校园横幅是品牌辨识，业务区避免装饰竞争。
STORY：首页快速查下一节与校园服务；课表/待办独立；社区交流、消息和个人资料继续走原有路径。
FIRST VIEWPORT：保留首页横幅和课程优先顺序；五入口底栏贴合系统安全区域。帖子作者、正文、图片、互动依次分层；操作至少44px。
FORM：基于既有产品代码的系统优化，不采用新的构图模板或新框架。
FINISH：检查前后同尺寸截图、现有功能回归与可用原生编译；明确合成数据、失败记录及待真机项。
