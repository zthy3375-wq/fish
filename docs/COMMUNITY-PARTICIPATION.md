# 头像与轻量回应 · test.8

基于 `cbe9e3e` / PR #68，新分支 `feat/community-avatar-responses-20261116`。Android 测试版本 `1.3.0-test.8 /158`，原包名；iOS 保持原生 SwiftUI / iOS 16。正式渠道保持 `1.2.4 /150`。

## 本轮范围

- 我的社区可选取照片，先预览居中裁切的方形头像，确认后上传；失败保留预览，支持重试、替换和恢复默认头像。
- 两端将图片压缩至不超过 512 像素的方形 JPEG；服务端重新解码、裁切并编码，去掉文件名、EXIF 等元数据。头像复用私有图片存储和短时签名链接，头像与帖子图片的用途隔离。
- 头像用于公开作者、评论、自己与公开主页。匿名发言和泛化互动提醒不返回个人头像或账号 ID；头像加载失败回退到昵称图标。
- 帖子列表及详情提供“我也一样 / 抱抱 / 有用”。每个账号每帖最多一种，点当前项取消，点其他项切换；与赞、收藏独立，网络失败回退，返回同步状态。轻量回应不自动关注讨论。
- 作者收到泛化身份的应用内提醒；同人同帖重复点击、切换不会不断生成新通知，取消后提醒隐藏。已读状态保持。没有系统推送。

## 数据和兼容

schema 4 为附加迁移：媒体用途、成员头像引用、新回应表及通知类型；保留现有帖子、评论、关注和已读。后台返回 `avatarsEnabled` / `responsesEnabled`，旧后台不提供时两端隐藏新操作。兴趣分区、关注用户、搭子帖、活动徽章不在本轮范围。

头像引用由服务端事务验证所属人、用途、就绪与删除状态；活跃头像不进入过期图片清理。新表与辅助函数沿用私有数据库权限。测试合成数据不会进入线上服务。
