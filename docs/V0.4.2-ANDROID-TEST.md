# v0.4.2 Android 教务测试版

本分支从 main `376c8ede` 创建，仅移植 PR #2 的正方格式解析器、人工样本和相关31项测试；未合并整个 PR #2。没有正式部署或合并 main。Android 测试版不等于学校官方授权接入，尚未用真实学生账号联调。

## 安装与实际操作

- 安装 debug 签名的 `handan-campus-v0.4.2-diagnostic.apk`，包名 `org.handancampus.app.diagnostic`，名称“邯郸校园·诊断”。与原 App 并排安装，不覆盖原 App 的数据库或签名。最低 App API23，教务实验窗口仅 Android 9 / API28 以上启用。
- Android 如提示允许当前下载应用安装未知来源，请仅针对本次下载来源按系统设置操作。测试版不是正式商店发布。
- 先在教务的“作息与设置”核对真实学期开学日、第一教学周和每节课时刻。本机的45分钟默认作息明确是示例，不能当学校官方作息。配置不符时不要确认保存。
- 教务 → 教务服务/概览 → 官方教务 → “测试教务连接 · 开发者诊断”。阅读说明，勾选本人数据处理确认，点击“登录邯郸学院教务系统 · 实验窗口”。
- 在学校真实网页自行输入账号密码、完成验证码等验证，手动进入并查询**本人**课表。应用不会代填、读取或记录登录表单内容。
- 点击**原生窗口底部**“检测课表结构”。此时只返回课程结构/字段存在性，不返回课程名。若需分享诊断，选择“返回脱敏报告”，回到 fish 后审核 JSON，再主动复制/导出。
- 若结构已识别且没有异常/特殊安排，选择“继续查看网页”，再点击“读取课程供本机预览”，确认仅在本机读取本人课程。窗口返回 fish 前清理会话，再展示课程预览。
- 逐门核对课程、教师、教室、星期、节次、周次，检查冲突与错误；再次确认学期和作息。点击“确认保存独立学校课表”，创建新的 `school-page-*` 学期，不替换原个人课表。首页/日/周课表共用现有模型，重新打开后仍可本机查看，来源明确标为“学校网页导入 · 非自动同步”。
- 用系统返回可在学校窗口返回网页历史；关闭/离开实验窗口会结束本次会话。后台切换会关闭实验会话，避免其在后台持有登录状态。强制杀进程可能无法执行清理回调，下次打开实验窗口先清 Cookie/站点存储再加载，不自动恢复登录；不要据此声称已经保证任意崩溃下磁盘无残留。
- 备用“打开学校官方网页”使用系统浏览器。浏览器会话归浏览器管理，fish 不读取 DOM/Cookie、不知道登录结果。其“检测当前课表页面”只生成边界报告；实际结构检查必须用实验窗口内原生按钮。

## 已实现的实际读取机制

独立、`exported=false` 的原生 Activity，在独立进程与 WebView data-directory suffix 中运行，与 Capacitor 主 WebView 分开。只允许 HTTPS 的 `jwgl.hdc.edu.cn`、默认/443端口，无 userinfo；登录路径不执行解析。顶层导航及子资源限制到同一校方域名，未知认证跳转直接阻止，不静默添加认证域名，也不复用系统浏览器会话。学校改版/需要外部验证码或 CDN 时可能无法登录，需用户说明不含查询参数的必要域名再核实。

无 `addJavascriptInterface`、无远程适配脚本下载、无网页可调用的原生文件/权限接口。用户必须点击原生按钮，才用 APK 内固定 JS 读取明确容器：`#kbgrid_table_0`、`#kblist_table` 或明确的 `window.kbList`，也检查有限数量的同源 iframe。只从这些容器取课程字段，不遍历全部页面正文、请求头、window、storage 或网络响应，不读取输入框、Cookie、Token、CSRF，不注入登录流程。不猜测或请求课表业务端点。

结构报告只含固定枚举、布尔值和有界计数；实际课程字段仅在用户第二次确认后传回本机内存预览，不写诊断文件、不自动上传。任何异常条目、未知实践课或 iframe 安全限制均提示并阻止课程保存，不把空课表当清空指令。解析器必须使用用户确认的学期与作息；单双周/自定义周、多安排、重复和冲突复用原模型。

TLS 错误调用 cancel；不允许混合内容、文件/内容 URI、第三方 Cookie、弹窗、网页权限和文件选择。关闭 WebView 远程调试；学校窗口使用 FLAG_SECURE，避免认证窗口被屏幕录制。不会采用 SSL 放行或 UA/认证绕过。应用备份关闭，认证不进课表备份。

## 会话与同步边界

这次交付的是**本人主动页面检查→本机课程预览→确认保存**的实验链路。学校许可未被独立核实，界面确认代表用户声明处理范围，不替学校授予第三方权限。

保留 `AuthorizedAcademicConnector`，不把网页课程导入注册为“学校已授权 API”。以下状态分别处理：网页由用户自行登录；用户主动执行结构检查；本机解析可能成功；第三方同步授权仍未验证；持续自动同步未实现。

未提取或加密保存 Cookie，没有跨启动会话复用、前台自动刷新或后台持续同步。不能承诺下次无需登录。只有真实账号读取通过、实际会话/访问契约得到确认后，才实现 Keystore 支持的专用凭据适配及隔离学校数据更新策略。学校课表当前保存为新学期分区，不按数组位置覆盖旧课程；重复导入会创建新分区，尚不是增量同步。原有个人课表、CSV/XLSX/ICS、备份和设置不变。

iOS 工程保留；Android Activity 与数据目录不视为 iOS 实现。未来 iOS 认证/会话存储单独适配，当前不能在 iOS 使用实验窗口。

## 开源源码研究

- ZZUPocket 固定提交 [`bef6b711`](https://github.com/3beuml/ZZUPocket/tree/bef6b7111866aeab035e4b61cc41c8d64b80e4b6)（MIT）：实际阅读 `CasClient.kt`、`AuthRepository.kt`、`TokenStore.kt`、`EasClient.kt`、`GmsScheduleSource.kt` 与认证/本科/研究生接口文档。其 JWT 路线有已知公钥、MFA、认证与教务接口；AuthRepository 校验到期并清二级令牌。研究生路线从 WebView 会话转入 CookieJar，凭据保存在 Keystore 支持的 EncryptedSharedPreferences，退出清 jar/store。接口、错误码、时效和域名都是郑大专用证据，fish 不复制其密码登录、Cookie 提取和接口常量。
- 拾光应用 `feabb68f`、warehouse `f55319f`：实际阅读通用正方 HTML/list/grid 适配、GDUST 的 kbList 映射、WebBridgeProtocol/Handler、WebView 与作息模型。借鉴适配分层与多安排/作息映射；不复制其通用原生桥接、Cookie 代理、混合内容或远程脚本执行。代码为独立实现；原项目许可证不变。
- Android 官方文档：[Custom Tabs](https://developer.android.com/develop/ui/views/layout/webapps/overview-of-android-custom-tabs)、[WebView 原生桥接风险](https://developer.android.com/privacy-and-security/risks/insecure-webview-native-bridges)。系统浏览器没有已验证的回调/DOM交接，本次提供独立受限 WebView 作为实验，而非谎报 browser login 授权成功。

## 构建与验证

```sh
npm ci
npm test
npm run build
npm run build:diagnostic
npx cap sync android
cd android
./gradlew testDiagnosticUnitTest testReleaseUnitTest assembleDiagnostic assembleRelease
```

`build:diagnostic` 才启用网页构建标记，Gradle `diagnostic` 才启用原生标记，两者同时满足才显示入口。debug/release 默认原生开关为 false；普通 Web、iOS 和手改 hash 均不开放工具。APK 含 debug 签名，不是可上架签名版本。GitHub Actions Android test APK 工作流会在本测试分支/同仓库 PR 上构建并上传14天 artifact，不发布 Release、不更新线上站点。

浏览器测试使用原生桥接替身与人工课程，不是真机或真实学校认证。学校登录跳转、验证码、真实 DOM、WebView 兼容性、特殊教学安排、作息准确性、强制结束生命周期等仍需用户在自己的手机按上述步骤测试。导出前只审核最小结构报告，勿分享密码、Cookie、完整 HTML、HAR 或个人课程截图。
