# 校园周边 V1.0 · 测试版

- 首页校园生活新增「校园周边」，可按分类查找门店、收藏、拨打门店电话和打开导航。
- 学生资格核验后可领专属优惠。券包展示未使用、已核销与失效记录，可到店出示二维码或数字码。
- 校园福利广告在首页和校园周边指定位置展示，标明「广告」并支持举报，档期结束后自动收起。
- 商家工作台支持资料提交、优惠管理、素材审核、核销、合作有效期和推广统计。
- 商业管理独立授权，支持资质及素材审核、合同、库存、排期、线下到账登记、违规下架和广告总开关。
- 测试分支基于 Android 旧 WebView 与标题授权修复，以及 iOS 接水和社区布局的验证代码。并装 APK 使用独立包名。
