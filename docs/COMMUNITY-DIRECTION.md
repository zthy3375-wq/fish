# 校园泛娱乐社区方向（2026-11-15）

用户希望把社区从树洞扩展为校园泛娱乐空间，并将树洞入口移到课表和待办之间。方向已进入实施，test.7 已完成社区入口、互动消息、讨论关注及公开主页代码；以 [本轮记录](COMMUNITY-RETURN.md) 区分已实现与后续事项。

## 当前粗糙感的来源

已有版本把账号、匿名、图文、评论、分页和错误恢复做通了，但发现内容、认识同好、收到反馈这三条路径仍不完整。当前分区以校园日常、求助、学习和搭子为主；自动生成的头像、基础账号页，以及单一帖子流，让不同兴趣缺少可辨认的空间。最新/热门是排序方式，还没有形成针对兴趣的内容发现。

此前缺少回复/赞消息中心和作者主页。test.7 补齐消息、公开主页和关注讨论；关注用户及兴趣推荐仍待实现。单纯继续增加转场或装饰，难以解决这种回访动力不足。

## 入口与层级

本轮实际改动：底部顺序为首页、课表、社区、待办、我的。树洞使用普通导航项，保持统一点击区域；首页原树洞大入口移除，个人页的账号入口进入同一社区页面。列表和未登录入口显示主导航，帖子详情、发帖、账号操作及弹层暂时收起主导航。切换主 Tab 不积累返回栈。

总入口已改名“社区”。现有分区及旧帖子保持兼容；匿名树洞独立分区的迁移另行实现。

## 初期四个内容分区

| 分区 | 主要内容 | 适合的轻量机制 |
| --- | --- | --- |
| 校园日常 | 食堂、校园照片、日常趣事、吐槽 | 每日话题、热门讨论 |
| 兴趣娱乐 | 游戏、动漫、影视、音乐、摄影 | 兴趣标签、作品话题 |
| 搭子广场 | 开黑、健身、吃饭、看电影、活动 | 时间和人数，标记已约满 |
| 匿名树洞 | 情绪表达、困惑、匿名交流 | 帖内稳定匿名身份、楼主标识 |

先让多个兴趣共用“兴趣娱乐”，用标签过滤；等某一兴趣持续有内容再拆区。保留原学习/求助帖子及其分区标识，迁移需有映射和兼容读取。初期不要按游戏名建立大量空分区。

## 页面与交互方案

1. 社区首页：顶部只保留发现/最新等主要入口，关注关系实现后才加入“关注”；下面是四个分区与一条真实运营话题，再进入帖子流。推荐位不得使用虚构热度或假帖子填充。
2. 信息流：头像昵称和时间、标题/摘要、图片、所属话题、评论与赞形成固定层级。单图、图集、纯文字使用各自合适的排版。标题和摘要不重复；图片保持统一裁切策略，长图可辨认。
3. 帖子详情：先交代作者和标题，再阅读正文和配图；长图不会把作者信息挤到读完图片之后。正文/评论切换、回复作者、展开楼中楼和底部互动保持稳定位置。
4. 评论：明确楼主和回复对象，保留两条楼中楼预览；增加热门/最新切换需有真正后端排序。表情用于表达，不能挤占阅读空间。
5. 发布：按“选分区、写内容、加图、选身份”排列；投票、搭子帖等新增类型分步实现，先保留稳定的文字/图片草稿和失败重试。
6. 个人页与消息：允许上传头像、设置简介和兴趣，展示公开帖子与收藏入口；先做回复我、赞了我和系统处理通知，再做关注。匿名帖子不能通过公开主页、关注列表或通知接口反向暴露作者。

## 视觉方向

以白底、清楚的正文、细分割线和一致的图片网格为主。品牌色只用于选中状态和主要操作，分区用克制的独立图标和少量色彩。避免给每块内容都加大圆角、阴影和渐变；列表密度根据真实文字和图片调整。夜间和大字模式、键盘弹起与减少动态效果应与常规状态一起验收。

动画优先表达状态：进入帖子、回复面板、点赞结果、返回阅读位置。以真机滑动、系统返回、键盘和加载时序验收，不以“动画数量”作为完成标准。

## 实施顺序与验收

- 第一阶段：本轮导航改动；接着统一社区首页、帖子卡片、详情、评论和发布的视觉规范，用同一批真实授权内容完成完整浏览路径。
- 第二阶段：社区回复/赞通知、可编辑头像与作者主页；匿名权限、未读数和跨设备同步一并实现。让发布者能收到反馈并回到对应讨论。
- 第三阶段：话题页、搭子帖状态和投票；增加稳定运营的每周主题与兴趣讨论。推荐先使用透明的时间与互动规则，内容积累后再考虑个性化。

验收重点：从主导航进入、浏览不同格式帖子、回复、离开与返回、收到反馈并进入原讨论；分别验证空数据、慢网络、失败、匿名身份、账号退出和 360/390/430 px 的排版。记录真实日活、发帖人数、回复率和次日回访后再判断分区与推荐调整。
