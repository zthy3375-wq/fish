# v0.5.0.4 真实学校 HTML 课表适配

> 历史记录：本文描述对应版本开发时点；当前功能和最新真机反馈以 [STATUS.md](STATUS.md) 为准。

2026-11-06，用户在云端官方页面自行登录后，实际检查了本人课表。没有读取密码、Cookie、认证令牌；没有将学生姓名、学号、课程或教师原始内容提交仓库。

实际菜单：个人课表查询，模块 N2151，`/kbcx/xskbcx_cxXskbcxIndex.html`。query `gnmkdm=N2151&layout=default`。页面有 GET requestMap 和 POST ajaxForm，均为同一路径；选项 xnm/xqm 在真实页面分别为四位学年与3/12。**更正：上述观察是浏览器执行脚本后的 DOM，不是原始 HTTP 响应。v0.5.0.5 实际阅读学校公开 xskbcx.js 后，确认该展示页通过 POST /kbcx/xskbcx_cxXsgrkb.html 获取 JSON。此前把渲染后的 DOM 当成服务端 HTML 的结论错误，已修正查询路径映射。**

真实 DOM 中确认3条有星期/节次的课程安排和5条按周的实践安排。浏览器只读结构提取检查显示，3条课程的课名/时间/教师/教室全部匹配；5条实践的“课名■教师(共n周)/周次”格式全部匹配。用户数据不作为测试样本保存；测试用例新建了匿名人工内容，但保留相同结构。

此前缺陷：

1. 通用 `/kbcx/` 菜单选择可能先选中班级课表。现在只选择 `xskbcx_` 本人课表菜单。
2. 真实页面名是 cxXskbcxIndex，旧版原生兜底白名单只有 cxXsgrkb，导致自动读取兜底根本没有进入。
3. 老解析教师/教室拿到的是图标内部的空 font。现在读取 p 的直接 font 子元素。
4. 理论/实验网格以外还有实践课程页脚。现在保留其课程、教师和周次，显示在课表下方，不编造星期和节次。

实现先解析实际返回的 HTML，不能完整解析就保留旧缓存；不要求用户检测、导入或导出。学校作息查询失败仍使用此前学生提供13节作息。第一教学周日期仍是本机配置，未验证官方校历，不能声称日期已由学校接口确认。

验证：vue-tsc、Vite构建、174项自动化测试通过；Capacitor同步与Android testDebugUnitTest/assembleDebug通过。浏览器真实数据结构已验证；新APK的Android自动请求、落盘和跨启动恢复仍待用户安装验证，不把浏览器验证等同于Android端到端验收。
