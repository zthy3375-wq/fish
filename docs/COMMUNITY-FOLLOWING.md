# 关注用户与关注动态 · test.10

基于 PR #70 / `8eaa179`，分支 `feat/community-following-20261116`。Android `1.3.0-test.10 /160`，原生 SwiftUI / iOS 16 同步实现；正式更新保持 1.2.4 /150。

## 本轮范围

- 公开同学主页关注/取消关注；独立“关注动态”内容流，仅展示当前关注用户的公开帖子。保留广场、我参与的和关注的讨论。
- 关注动态与分区、兴趣、搜索、最新/热门、分页和详情返回共同生效。切换失败保留旧内容并恢复筛选；取消关注后不再混入旧分页响应。
- 我的社区增加“我关注的人”，提供分页、打开公开主页、取消关注和失败重试。名单只由当前账号查看，不提供公开粉丝名单/粉丝数。
- 匿名帖子与匿名评论不暴露关注标记、头像或账号标识。隐藏匿名讨论不会改变关注状态；屏蔽公开身份会解除双向关注，恢复屏蔽不自动恢复关系。注销清理关注边。
- 操作由服务端确认后更新；重复请求幂等，网络失败保留原状态，账号退出后的迟到响应失效。关注和取消不发送互动通知，帖子更新通过关注动态查看。
- 关注用户与“关注讨论”独立，关注用户不自动订阅所有评论。旧后台未启用 followingEnabled 时，两端隐藏入口并继续支持原功能。

## 数据与验证

schema 6 追加私有 hyt_follows 表、分页索引和公开主页的当前用户关注状态，不迁移/重写旧帖、匿名身份、收藏或讨论关注。关注名单和动态仅从真实关系读取，没有示例账号进入线上服务。
