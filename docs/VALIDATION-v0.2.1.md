# v0.2.1 · 首页课程区域补充改造

> 历史记录：本文描述对应版本开发时点；当前功能和最新真机反馈以 [STATUS.md](STATUS.md) 为准。

基线：GitHub main `1c18227`，此前没有已提交的 v0.2.1。

## 修改范围

- 下一节课：第一行标签与动态倒计时；第二行课程/教室/箭头；第三行日期/时间/教师。整张卡片为单个button，支持键盘激活，去掉原有section点击与嵌套button的非一致点击区域。
- 今日课程：一个圆角描边容器，内部细分隔线；复用CourseCard，首页传grouped，课表页外观不变。开始/结束时间、课程色标、状态和教室/教师保留。标题可省略但DOM及详情保留全文。
- 首页垂直节奏：减少头部、问候语、课程标题和内容之间留白，不降低课程标题字体。列表不设最大高度，0/1/6/更多课程自然扩展。
- 导航：胶囊仍保留，但由fixed覆盖内容改为正常布局中的独立dock。页面壳为100dvh，main独立滚动且允许无限内容；底部空间包含safe-area-inset-bottom。教务和个人中心仅继承此避让，不重新设计其内容风格。
- 模块跳转滚动复位指向新的main滚动区；原History/Android backButton处理保留。
- 版本0.2.1，Android/iOS构建号3。没有新增教务接口、课程编辑或真实学校数据存储功能。

## 尺寸目标，尚非实测

- 今日课程行min-height 68px，紧凑模式64px；文字换行可自然增高，没有强制固定height。
- 三条标准行的最小容器高度约206px（3×68 + 上下描边）；旧布局最小高度244px（3×76 + 两个8px间隔）。这是CSS约束计算，不能当作浏览器像素测量或已实现的高度收益。
- 下一节课目标为紧凑三行，实际高度取决于字体、倒计时与辅助信息换行。没有取得真实测量值。
