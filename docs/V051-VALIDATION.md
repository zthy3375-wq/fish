# v0.5.1 导航与移动端验证

## 变更范围

基于 main `f6777f2`，独立分支 `feature/navigation-v051`。未修改学校认证、查询脚本、同步引擎、会话存储或学校/个人数据的持久化格式。

- 保留首页、课表、教务、我的；删除汉堡菜单和侧边导航。
- Tab 替换根页；二级页面记住原入口；浏览器和 Android 使用同一返回逻辑。弹窗先于页面关闭，未保存事项会询问是否放弃，返回先关闭该确认框。
- 按学期保留课表周次、星期、日/周视图；保留成绩筛选、搜索词与页面滚动位置。这些 UI 状态在本次进程内保留，学校数据缓存和选中学期继续持久化。
- 课表右上角＋添加事项；学校账号和个人课表/备份管理集中在我的。教务中心采用单一功能列表。
- 紧凑同步条、可展开错误、精简课表顶部、保留底部导航独立空间和系统安全区、支持减少动态效果偏好。

## 真机最小回归

请优先覆盖安装，保留原数据；签名冲突时不要直接卸载。v0.5.1测试包沿用本次工作环境的测试签名，CI环境的debug签名不保证与之相同。

1. 打开已有真实课表，切换周次、日/周视图、学期，再切换其他Tab后返回，检查状态。
2. 从首页进成绩后返回应回首页，从教务进成绩后返回应回教务；切换Tab后重新进入成绩，筛选仍保留。
3. 打开课程详情后按系统返回只关闭详情；添加事项并修改，返回出现放弃确认，再返回应留在编辑页。
4. 检查学校账号仍连接、刷新后真实课表和成绩可用；断网重开仍可看旧课表，个人事项与备份保持可用。
