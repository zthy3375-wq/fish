# v0.8.6 原生洗衣订单

## 用户操作

胖乖钱包 → 扫描机身二维码 → 选择程序 → 查看费用 → 确认支付并洗衣。仅最后一个明确确认动作允许建单/付款。余额渠道和支付宝渠道按服务端返回的可用性展示。支付宝 SDK 处理官方签名付款参数，其余设备、程序、价格、订单与进度留在应用内。

一个当前洗衣会话加密保存于原胖乖会话 vault。关闭页面或重启可继续查询，重新登录同账号保留当前订单；换账号/退出清除本地信息。进行中的订单阻止第二次建单。本轮暂不支持同时洗多台。仅钱包页面前台每15秒查询，连续3次失败停止自动查询，保留手动查询；不承诺后台通知。

程序标价不当作应付价。预览、下单后订单金额分别核对；变化后要求再次确认。报价60秒有效、原生单次消费，不接受前端传入金额、设备编号或任意订单编号。付款参数留在 Kotlin，不经 JS。订单绑定订单号、订单ID、设备、程序；不匹配则停止付款。

创建前持久化 creating；创建响应丢失时保留未知状态并阻止自动重建。查询状态可从最近20单找回创建前未存在、设备/程序匹配、创建时间处于本机发送前5秒至后120秒且唯一的新单，再核对详情身份，只恢复查询。时间偏差、缺失字段、匹配多单时保留未知，需核对官方订单，不提供一键清除未知交易保护。付款前持久化 paySent，异常和SDK返回均只查询原订单，不自动补扣。SDK取消后仍保留原订单，可查询/显式取消，以服务端结果为准。取消需重新查询未付状态，平台裁决付款竞争。

已付款、确认启动、平台完成分别展示。预计结束时间来自 order/detail.completeTime，Asia/Shanghai解析；归零只显示等待确认，不标完成。洗衣无强行停止按钮。饮水码可识别和查看设备，但尚未加入开水、暂停、结算。

## 协议依据

独立实现公共协议事实，未复制参考项目源代码或测试。参考：

- https://github.com/Mercury000/HUEL-yktwx ，commit 1bb98ea5bc87e9a217ce6b8af10c47046aa92c73，docs/life-devices-laundry.md 与 LifeDeviceApi，公开记录扫码、报价、设备检查、余额建单/付款、启动、完成及支付宝参数。其完成证据主要覆盖零元桶自洁，不代表本校付费洗衣成功。
- https://github.com/Night-stars-1/wash ，commit ffc25d25b980f8bef66b41d7d015936989ec825e，ApiService 和响应模型，交叉核对 trade/create、order/detail、支付宝 SDK payV2。旧项目对 orderNo 的用法不同，本轮采用较新抓包记录的 tradeNo。
- 用户提供两种机身二维码，离线解析为 h5.qiekj.com/skip 的 SN 与 NQT 参数。实际编号、照片不入 git。洗衣机旧贴纸含验证码步骤，本校是否需要该步骤尚无接口证据，不猜造验证码或跳过设备检查。

新增固定接口：trade/preview/v4、payChannelRoute/prePay、trade/check_device_status、machine/sync、trade/create、pay/unify/pay、pay/unify/prePay、order/pay_status、machine/device_is_start、order/detail、payChannelRoute/againPay、order/cancel。金额字符串校验不超过两位小数。仅非蓝牙、先付款洗衣设备可进入交易；health、同步和支付渠道信息缺失时不放行。

广告优惠参数采用空集合和 isAutoSelectPromotion=0。参考项目明确此请求与其抓包的促销参数不同；不硬编码别人账号的促销ID。该组合是否被本校运营商接受仍需真机验证。平台异常不绕过验证或重放付款。

支付宝使用 com.alipay.sdk:alipaysdk-android:15.8.42，限定该 group 的阿里云 Maven 公共镜像。服务端签名字符串原样交给 SDK；SDK结果不直接视为到账。微信、银联及其他渠道暂未接入。充值仍为原官方商户充值入口。

## 验证

新增原生交易回归：扫码不建单、报价过期、渠道缺失、设备检查超时、价格变化、订单身份不符、创建响应丢失、付款响应丢失、SDK返回与平台状态分离、取消前重新查状态、敏感字段不进入桥接快照。

新增 Vue 回归：程序选择/报价不扣款、取消确认、单次明确提交、报价过期、不可用渠道、已付未启动、预计时间归零、未知下单状态。移动端合成桥接回归覆盖360/390/430宽度的确认页和订单进度。

最终本地检查和Android构建状态以PR检查为准。合成测试不等于真实账户、支付或机器运行验收。
