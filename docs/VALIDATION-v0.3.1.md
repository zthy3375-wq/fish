# v0.3.1 验收记录与使用入口

日期：2026-11-06（北京时间）。代码基线 `830476e`，恢复分支 `archive/v0.3`。沿用原 Vue/TypeScript/Vite/Capacitor、MIT 许可证、Git 历史及三主入口。

## 实现与入口

- 点击“教务”主导航直接打开周课表；顶部明确提供添加课程、导入、作息与设置，底部可进入其他教务服务。
- 横向周一至周日、纵向实际作息节次；跨节课程按坐标轴起止定位，空课间适当压缩，存在自定义课的课间展开，首末节外时间也能显示。今天和当前周独立标记。
- 点击空白节次直接进入全屏课程编辑，自动填星期、节次与相应时间。首屏优先名称、教师、教室；时间/单双周/自定义周按安排展开，支持多个安排及不同教室，颜色备注折叠。
- 重叠课程在手机上以合并入口显示数量，点开后完整列出各门课程，再进入单个详情、编辑或确认删除。定位引擎仍保留每个原安排和冲突lane，不把课挤成多条极窄文字。
- 作息与设置 → 作息：可增加/移除节次、调整开始结束时间、切换现有方案或另存新方案。应用前预览联动变化和冲突，确认后保存；独立时间/旧课程不移动。
- CSV/XLSX/ICS 继续使用原解析、文件安全检查、预览和确认合并/替换；新增编译内置适配器契约、字段映射说明和更明确的错误提示。无学校登录或抓取。

## 浏览器真实流程

云端浏览器，同源iframe分别以360×800、390×844、430×932实际渲染；这是Web视口验收，不等于手机真机。

1. 在原v0.3数据仍存在时打开新版，原7个安排成功保留，课名、教师、教室、时间与第一周日期未丢失。
2. 点击周五第3节空白格：全屏编辑预填周五、3节、10:00–10:45。填写名称/教师/教室，改结束节次为4，保存后周表显示10:00–11:35跨节课程。
3. 新建另一门同日3–4节课程：保存首先提示时间冲突；明确勾选保留后成功，点“2门重叠课程”完整列出两门课及时间、教室、教师。
4. 编辑一门原课程，增加周一第1节单周安排和不同教室。第9周出现，第8周隐藏；第9周非当前周时没有错误的今天高亮。需等待轻量转场结束后读取最终DOM状态。
5. 作息另存预览只列出2个联动安排由10:00改为09:55，并显示冲突。确认后日课表两门显示09:55–11:35，原独立课程仍为08:00–09:35。重载后该作息及课程恢复。
6. 未保存编辑点返回，显示退出确认；“继续编辑”保留名称，再确认放弃才退出。
7. 360和430px下 documentElement.scrollWidth 等于clientWidth；390px也已实际检查。课程标题实测12px，地点11px。示例两节块高约143.77px，单节/午间45分钟块约66px（含4px上下间隙；单位随rem布局缩放）。作息调整后独立课程从节内开始，位置会对应偏移，避免强行吸附。
8. 430px滚到底：main.scrollTop=874、scrollHeight=1631、clientHeight=757，footer.bottom≈824.84、navigation.top=845，最后内容完整可见。

截图提供改造前390px深色周表、改造后390px深色周表、360px浅色周表和390px全屏编辑。课名中的“测试/验收”是浏览器本机验收数据，没有写入部署的课程数据源。对比后图比前图多一门现场添加的跨节课程，保留了原样本，非像素级同内容截图。

## 数据迁移与回退

保留 `handan-campus.schedule.v1` 存储地址，payload升级为2；Web仍为同一IndexedDB数据库/对象仓库，原生仍为Preferences。v1课程全部设为custom，保留明确时间，新增示例作息关联。写入升级数据前保存原快照到 `.before-v2`，可从“数据 → 导出升级前原始快照”取得v1兼容备份。Web迁移使用同一事务；读到已升级v2时不以旧快照覆盖。读取/恢复拒绝未知版本，白名单重建字段。

仅新建或用户主动切换为period的安排随作息改变。切换作息前必须核对预览，另存方案只关联当前学期。备份恢复同时支持v1/v2，恢复后的提醒仍默认关闭。
