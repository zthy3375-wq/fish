# v0.7.2 学习通反馈修复

修复验证码重放上下文与不完整作业分页的错误保护。用户诊断数据和反馈文件不纳入提交。

本次修改：

- 修复 rememberChallenge 保存 verificationReferer 后立即删除它的错误；验证码 WebView 和原生验证重放使用保留的来源页面。
- 分页结构异常时返回已读记录，保留本课程前面页面的结果。
- 支持官方返回的作业列表 iframe 与非 li 的 goTask 节点；仅跟随已有的官方只读地址。
- 诊断补充独立的失败作业页面 host/path、容器/iframe/事件节点计数和请求阶段，避免后续验证码请求覆盖失败页面位置。仍不导出签名链接、Cookie、课程/作业标题或完整 HTML。
- APK versionCode 72，学习通预览包使用独立 v072 applicationId，避免不同 CI 测试签名冲突；旧版仍可保留，新版首次需连接学习通。

自动化测试验证解析分支和验证上下文保存；真实验证码通过后是否继续成功、课程完整扫描及未知页面结构仍需原账号真机验证。此版本不能视为已修复所有 WORK_SCHEMA。

## 课程整理

学习通作业默认按平台课程编号和班级编号分组，可折叠。课程内先显示待提交与状态待核对的作业，再显示已截止和已提交记录。每组显示各状态数量。旧缓存中缺失的课程名使用已同步课程列表补全，保留原任务编号、截止时间和个人规划；不跨班级借用名称。统一待办中的学习通任务也自动按课程归组，个人任务保留原分组开关。
