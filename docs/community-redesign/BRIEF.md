# 社区主流程改版 · test.18

模式Operate/Read：让邯院学生顺畅刷帖、读详情、回复和发帖。继承test.17首页成果，保留五Tab、小金鱼、既有浅紫白体系与深色主题，不重做身份、接口、权限、存储或后端schema；iOS16基线保留。

颜色继承校园紫#6843b5、淡紫#eee8f8、白#ffffff、底色#f7f6fa、正文#262233、辅助#696477。社区业务只用系统无衬线，名称/标题/正文/元信息按语义分层；金额、时间与计数使用等宽数字。不增加字体或插画。

阅读主线：顶部广场/关注/继续聊与分区保持；帖子作者、正文、图片、互动分组。长正文只有真实溢出才显示展开全文入口；配图保留顺序、原图和数量。正文阅读与评论有清楚的分组；楼中楼明确“回复谁”，回复上下文与编辑区域相接。固定互动栏保留点赞、收藏与评论，避让安全区和短屏。

写作主线：身份和发布分区在前，标题/正文统一写作面；附件以横向可操作缩略图带组织，保留移除、排序、投票与招募。显示真实图片上传数量和发布阶段；网络失败保留文字/附件/幂等ID，重试复用已上传图片。草稿保存状态只在最新版本实际写入后确认，保存失败提供原地重试。

特色是可直接读下去的校园讨论与明确的回复链，不加虚构热度、活动或用户内容。动效限于现有状态反馈，保留减少动态、键盘焦点、原生返回和实际错误。

验收：三宽度360/390/430，短屏回复、深色、长文、图文、楼中楼和发帖失败恢复；沿用真实PGlite/HTTP测试服务与合成账号，截图不冒充真实学校/用户。完整单元、共享协议、页面回归、原生测试与APK编译/原签名/资源核对。首页、接口、数据不回退，不合并main、不发布或推送更新。
