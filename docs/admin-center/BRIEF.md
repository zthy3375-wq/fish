# 社区管理中心第一版

面向现有moderator的手机操作页，继承test.18浅紫白与深色系统，五主Tab不变。入口“我的社区→管理中心”，内部待处理/内容管理/操作记录三栏；用户管理、站长授权及运营工具留到后续阶段。

待处理展示真实举报原因与时间，打开后看整篇帖子、目标评论与配图，独立填写处理理由，核对后才提交。内容管理支持标题/正文文字搜索、游标分页和从帖子/评论菜单直接管理。处理动作沿用删除/整篇暂停回复/7天禁言/无需处理，并支持整篇恢复回复。操作记录包含操作者、目标、理由、时间，可翻页及返回对象。

普通账号在服务端拒绝全部新管理接口；匿名作者仍沿用匿名投影，不增加真实账号、学校凭据、密码或私信读取入口。每次操作带不可变请求ID，失败重试不重复处罚；举报已由他人处理时返回冲突。生产角色和数据不变更。

本轮删除沿用现有内容/媒体清理，不提供恢复承诺；可恢复下架及图片保留策略未实现。新版后端能力声明moderationEnabled，旧后台继续显示原举报入口；新增接口/审计目标字段仅在隔离测试数据库验证，不自动迁移或部署生产。

布局：层级清楚的列表、少量语义底色、44px操作区、完整长文/理由、双确认危险操作；继承现有字体和配色，不加图表/虚构指标/资产。360/390/430、520px短屏与深色截图，真实PGlite/HTTP测试；Android版本test.19/169。实际设备与线上后台接通需单独验收。
